# 타슈 모델 목표 축소 실험

## 현재 데이터 조건

- 과거: 대여·반납 이력. 해당 시각의 실제 API 재고는 없음.
- 현재: API 재고 스냅샷. 제공받은 2026-09 자료는 평가에만 사용.
- 재고 하한·상한과 노출도는 자전거 이력에서 복원한 추정값이며 실제 API 관측이 아님.
- 현재 API 자료는 여러 실험을 이미 평가했으므로 향후 모델 선택의 독립 최종 시험으로 주장하지 않음.

## 축소 목표 1: 반납의 공간 배분

**질문:** 시간당 도시 전체 반납 건수를 *알고 있다고 가정*할 때, OD 그래프가
대여소별 반납 비율을 더 잘 예측하는가? 반납은 재고 부족에 따른 대여 절단 문제가
없으므로 구조의 공간적 장점을 먼저 분리할 수 있다.

- 학습: 2026-02-01 이전 대여이력 및 그 이전 OD만 사용.
- 비교: 같은 그래프 신경망에서 OD 전파만 제거한 모델, 학습 시드 0·1·2.
- 평가: 2026년 2월·3월 낮 시간 반납량. 실제 전체 반납 건수는 평가 중 공간
  배분 능력을 분리하는 **오라클 값**일 뿐 실제 예측 입력이 아님.
- 지표: 반납 1건당 공간 분포 교차엔트로피(낮을수록 좋음), 오라클 총량으로
  배분한 대여소별 MAE, 예측 상위 10% 대여소가 포착한 실제 반납 비중.
- 진입 조건: 세 시드의 그래프 개선 방향이 일관되고 2월·3월 모두에서 교차엔트로피가
  개선될 때만 다음 구조 실험으로 진행. 날짜 단위 부트스트랩으로 불확실성을 확인.

시드 0·1·2 결과 모두 두 달에서 그래프가 우세했다. 반납 1건당 교차엔트로피의
시드 평균 개선은 2월 `0.0139`, 3월 `0.0139` nats이고, 오라클 총량으로 배분한
대여소별 MAE의 시드 평균은 2월 `0.485` 대 `0.489`, 3월 `0.643` 대 `0.653`이다.
따라서 **공간 배분에는 OD 그래프의 작지만 반복되는 이득**이 확인됐다.
이것은 ST-GCN의 시간층이나 flow matching의 효과를 입증하지 않는다.

## 축소 목표 2: 반납의 공동 확률 시나리오

**질문:** Flow matching이 독립적인 대여소별 분포보다 여러 대여소가 동시에
붐비는 상황과 불확실성을 더 잘 표현하는가?

- 예측 대상은 **관측된 반납 건수**로 제한. 대여의 미관측 수요는 포함하지 않음.
- 시공간 인코더에는 학습·추론 양쪽에서 얻을 수 있는 과거 패턴 추정값만 입력.
  실제 직전 6시간 반납 건수를 한쪽에서만 넣지 않음.
- 총량을 알 때의 공간 시나리오를 먼저 평가하고, 독립 NB 및 단순
  Dirichlet-multinomial 시나리오를 기준으로 비교.
- 지표: 샘플 기반 energy/variogram score, 도시 전체·상위 대여소의 80/90% 구간
  포함률, 공동 상위 수요 사건의 재현율. 점 예측 MAE만으로 채택하지 않음.
- 진입 조건: 적어도 2월·3월에서 확률 예측 점수가 기준보다 개선되고,
  주변 분포의 평균 오차를 악화시키지 않을 것. 실패하면 flow 단계를 제거.

## 목표 3: 총량 예측과 현재 API 결합

목표 1·2에서 이득이 확인된 구성에 도시 전체 대여·반납 총량 예측을 결합한다.
현재 모델은 2026년 2·3월 총량을 상당히 과소예측하므로, 이 오차를 먼저
개선해야 한다. 이후 현재 API 재고를 **재고 시뮬레이션의 시작값**으로만 넣는다.
대여·반납 건수는 재고 순변화만으로 역산하지 않는다.

평가 지표는 품절 AUC뿐 아니라 확률 보정, 순재고 변화 MAE, 경보 상위 대여소
적중률이다. 기존 직접 품절 모델 및 단순 재고 기준보다 낫지 않으면 운영 목표로
확장하지 않는다. 최근 9월 API는 탐색적 평가로 표시하고, 독립 확인은 이후 별도
기간에 수행한다.

## 최종 목표를 수정하는 규칙

- 공간 배분만 개선: **대여소별 반납 공간 분포 예측**을 결과물로 삼고 GCN만 유지.
- 공동 시나리오도 개선: **상관된 반납 시나리오 생성**까지 목표를 확장.
- 총량과 API 결합도 개선: 그때 **현재 재고 조건부 품절·재배치 위험 예측**으로 확장.
- 어느 단계든 기준선에 못 미치면 그 단계의 복잡한 모듈을 제거하고 이전 목표에 머문다.
