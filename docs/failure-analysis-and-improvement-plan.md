# 어디서 막히는지와 다음 개선 실험

기준: H-0005·H-0006까지. 최종 아키텍처는 미정이다.
학습·설정 선택은 과거 다운로드 이력, 공식 재고 평가는9월 API라는 경계를 유지한다.

## 1. 가설

‘안 된다’를 한 가지 원인으로 묶지 않는다. 점출력과 손실의 불일치, 흐름 추정의 정보 부족,
상태 전이 가정, 관측 과정, 결합 의존성은 서로 다른 문제다.
GCN·Poisson·Flow Matching은 서로 다른 부분을 담당할 후보이므로 각 부분의 실패를 분리해서 비교한다.

| 원인 후보 | 현재 근거와 확정할 수 있는 범위 | 개선을 확인할 방법 |
|---|---|---|
| 평균을 MAE 하나로 해석한 문제 | H6에서 같은분포 중앙값으로 MAE0.632669→0.576346대. 평균은 RMSE에서 현재 유지보다 낮음 | 평균↔MSE/RMSE, 중앙값↔MAE, 확률↔Brier, 분포↔CRPS로 출력·손실 일치. 확률을 고쳤다는 주장은 하지 않음 |
| 현재 유지 이상의 수량 정보가 적음 | 중앙값의97.35%가 현재재고와 같음. 현재유지대비 MAE차의 두구간0포함 | 과거 자료의 추가 맥락이 검증 시점에도 제공 가능한지 확인. 정보 증가와 점출력 변경을 구분 |
| 완료거래율을 사건 시도율로 사용 | 관측변수의 차이·과거 실측재고 부재는 확인. 이것이 API오차의 몇%인지는 미식별 | 완료거래를 잠재수요로 승격하지 않고 노출시간 가정을 명시. 흐름의 내부 검증부터 개선 |
| 달력 평균의 시간 이전·수준 변화 | 과거와9월 사이 시간 차이가 있으나 원인별 기여는 모름 | 과거 안의 순차 발행시점·월/계절 검증. 건수 진단을 재고 정답 검증으로 대체하지 않음 |
| 공간 정보 부재·관계의 잘못된 의미 | GCN은 새 계약에서 미시험. OD이동·지리 근접·수요 의존성은 다름 | 같은 입력·출력·예산의 자기대여소/OD관계/치환관계 비교. 학습기간 전용 그래프와 누출 검사 |
| 독립·무기억 흐름의 한계 | 현재 과정은 독립시도 근사. 과거 OD·출발/도착시각은 결합/지연 학습 후보 | 독립 과정 대비 과거 공동 거래의 단순 표본/결합 기준선. 그 뒤 FM의 추가 가치 비교 |
| 운영자 이동·상태 조정·관측 지연 | 별도 로그와 같은기간 거래/재고가 없어 원인별 정답 없음 | 필요한 동시 자료·식별 가정 정리. API잔차를 재배치 정답이나 학습 보정량으로 재사용하지 않음 |

H6가 증명한 것은 첫 번째 원인의 제한된 영향이다. 나머지를 실제 원인으로 확정하거나 기여율을 만들지 않는다.

## 2. 실험

### 완료한 진단과 원문 근거

[H-0006 결과](H-0006-results.md)는 같은분포의 평균·중앙값을 비교했다.
[Gneiting2011 저자 원문 §1.3·Table5](https://arxiv.org/pdf/0912.0902)는 손실에 맞는 점출력을 구분하는 근거다.
이론은 모형 분포 아래 최적성을 말한다. 실제 관측의 성능 우위까지 보장하지 않는다.

[Gast2015 §2.2~3.1](https://www.pure.ed.ac.uk/ws/portalfiles/portal/23608488/Gast_et_al_2015_Probablistic_Forecasts.pdf)의
사건률 추정에는 비어 있지 않거나 가득 차지 않은 시간의 정보가 필요하다. 우리 과거 이력만으로 이를 재현했다고 할 수 없다.
H5/H6는 원문 재현이 아니라 완료거래율을 사용하는 별도 근사다.

새로 확인한 [Luo 외, Transportation2026, Data and method·식1](https://link.springer.com/article/10.1007/s11116-026-10753-7)은
같은 기간의 거래와10분 상태 관측의 불일치로 운영 이동을 추정한다. 상태자료가 없는 우리 과거 이력에 그대로 적용할 수 없다.
확인 범위는 재배치 식별 부분이며 차량 경로 최적화·추정 성능을 타슈에서 재현하지 않았다.
9월에는 동시 거래 로그가 없고 API가 검증 전용이므로 그 잔차로 새 학습 라벨을 만들지도 않는다.

### 다음 비교의 순서와 통제

아래는 **다음 가설 설계**다. 아직 동결·실행한 결과가 아니다.

| 순서 | 바꾸는 부분 | 대조군·반증할 질문 | 유지할 조건 |
|---|---|---|---|
| A | 과거 흐름의 시간·공간 표현 | 고정 달력·자기 대여소 대비 과거 OD관계가 추가 정보를 주는가? 관계를 치환해도 같다면 관계 의미의 근거가 약함 | 과거 순차 분할·가용 입력·같은 출력/손실/예산. 학습기간만으로 관계/정규화 생성 |
| B | 기록 거래의 분포·결합 가정 | 독립 사건 대비 단순 공동 거래 표본/결합 모형이 어떤 의존성을 보완하는가? | 같은 평균 맥락·자료·시간 범위. 주변 점수와 결합 점수 분리 |
| C | 결합 생성기 | FM이 단순 결합 기준선보다 정보를 보존하며 계산 비용을 정당화하는가? | 같은 조건·정수 표현·분할·평가·예산. 생성 내부 시간과 물리 시간 분리 |
| 병행 검토 | 상태·관측 과정의 식별 | 운영자 이동·실측 재고·관측 지연에 필요한 자료·가정은? | 정보 부재를 API시험 오차로 메우지 않음. 가정과 실제 정답 구분 |

A는 [아이디어별 공간 설계 초안](architecture-ideas-to-experiments.md)의 OD·자기·치환 비교를 구체화한다.
최근 거래를 입력으로 쓰는 연구라도9월에 그 입력이 없다면 그대로 가져올 수 없다.
먼저 달력·과거 학습 표현처럼 검증 발행시점에 제공할 수 있는 정보로 비교한다.
외부 맥락도 출처·발행시점·당시 가용성을 확인한 뒤 과거 내부 검증에서 정한다.

과거 내부 선택을 끝낸 모델은 따로 동결한9월 평가에서만 점검한다.
9월 점수로 그래프·크기·분포·분위수·보정·조기 종료를 고르지 않는다.
반복 평가와 선행 결과 노출을 밝히고 독립 시험이라고 부르지 않는다.

### 아키텍처에 반영할 원칙

`가용한 과거 맥락 → 흐름 추정/생성 → 상태·관측 가정 → 예측 분포 → 손실에 맞는 출력`

- GCN은 흐름의 공간 맥락 후보다. 공간 관계가 무엇을 알려 주는지부터 대조한다.
- Poisson은 먼저 단순 사건 과정 대조군이다. API재고 자체가Poisson이라는 주장과 구분한다.
- FM은 공동 흐름 생성 후보다. 큰 생성기가 수량 정보나 운영자 이동 정답을 만들어 주지 않는다.
- 상태 모듈은 비음수 경계·초기 상태·운영 이동·관측 과정을 명시한다. 실제 근거 없이 물리 용량을 만들지 않는다.
- 도시 대여/반납을 같은시간에 강제로 합계0으로 맞추지 않는다. 이동중 자전거와 시간 경계가 있기 때문이다.
- 평균·중앙값·0대 확률은 같은 분포의 다른 출력이다. 원하는 판단과 점수를 먼저 정한다.

## 3. 결과

현재 수량 점수 악화의 일부를 **출력·손실의 불일치**로 분리했다.
같은분포 평균의 RMSE는1.149779대, 현재유지는1.202860대였다.
중앙값 MAE0.576346대와 현재유지0.579567대의 차이는 작고 두보조구간모두0을 포함한다.
확실한 수량 예측 개선이나 운영 모델 채택 결과는 아니다.

같은분포의 CRPS0.453046·0대Brier0.125396은 중앙값으로 바꿔 개선된 확률이 아니다.
전체5~95%구간 포함률92.34%만으로 상태별 보정까지 입증하지 않는다.
재배치·계절 변화·사건 의존성을 개별 원인으로 단정하지 않았다.

다음 행동은 A의 과거 전용 공간 비교를 새 가설로 동결해 실행하는 것이다.
평가 출력은 이번 구분을 유지하고, B/C는 단순 대조군과 관측 가능한 학습 대상을 정한 뒤 이어 간다.
