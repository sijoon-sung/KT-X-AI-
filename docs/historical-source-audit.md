# 과거 대여이력 원본 확인

[자료 사용 계약](training-validation-contract.md)에 따라 dislab에서 수행한 원본 감사다.
새 모델의 성능 실험이나 검증된 학습 패널이 아니다.

## 1. 가설

사용자가 지정한 기존 과거 기록을 학습 출처로 확인하고, API를 열지 않은 상태에서
학습 전 해결할 원본 문제를 찾아 자료 계약을 세운다. 성능 우월성에 대한 사전 등록 가설은 아니다.

## 2. 실험

- 원본: 대전교통공사 타슈 대여이력 ZIP, 공개 파일명 기준 20260331 자료.
- 크기: 493,887,524바이트. SHA-256: `b43e78c373050d0aae2208db037538187066c565b7d5833f462b2ea94d42560b`.
- ZIP 내부 CSV 20개를 전수 읽고 원본 바이트 해시·인코딩·열·행 수·필수 값·시각 문자열 형식·파일 월과 대여 월을 확인했다.
- 실행: dislab CPU. 시작 `2026-10-30T19:19:14.312416+00:00`, 종료 `2026-10-30T19:20:42.685618+00:00`.
- API 패널·API 메타데이터·기존 API 모델은 읽지 않았다. 모델 학습·가중치 선택을 하지 않았다.
- 첫 시도는 모든 파일을 cp949로 엄격히 읽다가 두 번째 파일에서 중단했다.
  인코딩을 파일별로 명시하고 오류 문자를 대체하지 않는 방식으로 다시 감사했다.
- [공개 원본 목록](sources/tashu-historical-trips-source-v1.json)에 파일별 해시·열·집계를 보존한다.

## 3. 결과

| 항목 | 확인 결과 |
|---|---|
| 실제 대여 날짜 범위 | 2024-08-01~2026-03-31 |
| 원본 행 수 | 9,320,018행. 정제·중복 제거 후 학습 표본 수가 아님 |
| 인코딩 | cp949 9개, UTF-8 계열 11개 |
| 필수 대여/반납 시각·대여소 ID 누락 | 0행 |
| 열 수 불일치·미인식 시각 형식 | 각각 0행·0행 |
| 파일 월과 대여 월 불일치 | 203,545행 |
| 실측 재고 열 | 확인한 19개 열에 없음 |

2025년 12월 이름의 파일은 203,545행 모두 대여 월이 2025년 1월이었다.
이를 12월의 학습 정답으로 사용할 수 없으며, 그 사실만으로 다른 파일과 모든 행이 완전히 같은 중복이라고 확정하지는 않는다.
2025년 2·3월 파일명에는 시스템 장애 누락 안내도 있다. 빠진 기간을 정상 거래 0으로 취급하지 않는다.

대여·반납 시각과 대여소는 실현된 거래의 출처다. 거래로 복원한 재고는 실측 재고가 아니며,
향후 반납·다음 이용 기록을 쓰는 복원치를 과거 예측 입력으로 넣으면 안 된다.
API 재고 검증에는 거래 예측과 상태 예측의 연결 및 초기 상태·운영 이동 가정을 따로 정의해야 한다.

**다음 행동:** 월 불일치·중복·유효 시각·운영/누락 범위·대여소 대응을 처리할 과거 학습 입력 계약을 정하고,
새 가설·시간 분할·비교군·판정 기준을 동결한 뒤 과거 자료만으로 첫 모델을 학습한다.
API를 학습·모형 선택·보정에 사용하지 않으며, 검증은 모델 고정 이후에 수행한다.

**한계:** 이번 감사는 원본 바이트·구조·날짜 확인이다. 거래 중복·시간 역전·이용 기간·운영 여부·장애 시간·좌표 변화는
아직 전수 검증하지 않았다. 정규식의 시각 형식 확인은 실제 달력 날짜·시간의 유효성 검증과 다르다.
과거 자료를 이용한 새 모델 학습과 API 외부 검증 결과는 아직 없다.
