# H-0004: 다운로드 이력으로 첫 예측 기준선 학습

상태: 사전 계획 동결·미실행. 정확한 기준은 [가설 JSON](../research/hypotheses/H-0004.json)이다.
[자료 계약](training-validation-contract.md)에 따라 다운로드 이력만 사용하며 API를 열지 않는다.

## 1. 가설

**요일·시간대 패턴을 학습한 평활 평균이 대여소별 고정 평균보다 이후 기록 대여·반납 건수의
평균 Poisson deviance를 1% 넘게 줄일 것이다.**

복잡한 모형에 앞서 같은 자료로 재현할 수 있는 학습 기준점을 만든다.
[Lin 외 §5.2](https://arxiv.org/pdf/1712.04997)의 같은 대여소·시간 학습 평균 HA와
[Hyndman·Athanasopoulos §5](https://otexts.com/fpp3/toolbox.html)의 기준선·시간 순서 평가가 출발점이다.
요일 평활을 포함한 이번 구현이 그 논문의 HA·GCNN 재현이라는 뜻은 아니다.

Poisson deviance는 비음수 건수의 **평균 예측**을 비교하는 손실이다.
포아송 분포 적합·분산·미충족 수요·실제 재고 또는 결합 분포의 신뢰성을 입증하는 실험이 아니다.

## 2. 실험

| 역할 | 기간, 종료 미포함 | 사용 |
|---|---|---|
| 학습 | 2025-08-01~2026-02-01 | 대여소 집합·두 평균 모형의 계수 학습 |
| 내부 선택 | 2026-02-01~03-01 | 평활 강도 1·4·16·64 중 선택 |
| 내부 보류 | 2026-03-01~04-01 | 선택 완료 후 한 번 비교 |
| API | 사용하지 않음 | 후속 외부 검증으로 분리 |

자료는 [원본 목록](sources/tashu-historical-trips-source-v1.json)의 ZIP이며
[이번 입력 manifest](../research/datasets/tashu-historical-H0004-v1.json)에 해시와 역할을 고정했다.
시각은 한국 시간 조건부 해석이다. 정답은 적격 완료 거래의 시간별 **기록 건수**이며 실측 재고가 아니다.

- 파일별 인코딩을 엄격히 적용하고 실제 시각을 파싱한다. 월 불일치·필수 값 오류·역전·24시간 이상 거래를 제외한다.
- 정규화한 자전거 ID·대여/반납 시각·두 대여소가 모두 같은 완전 중복만 제거한다. 짧은 재대여를 임의로 합치지 않는다.
- 원본 월파일이 있는 월의 안쪽 날짜, 07~21시, 도시 전체에 적격 대여·반납 기록이 모두 있는 시간만 사용한다.
  월 첫날·끝날은 24시간 미만 거래의 월 경계 영향을 줄이기 위해 제외한다. 빠진 월·불명확한 시간은 마스크로 남긴다.
- 이 기록 범위 안의 대여소별 0은 **원본에서 적격 사건을 세었을 때 0건**이라는 뜻이다.
  대여소별 수집 완전성이나 실제 거래 0을 입증한 값이 아니며, 기록 범위 가정은 해석의 한계다.
- 학습에서 대여·반납 각각 100건 이상, 사건 있는 날 60일 이상, 학습 첫·마지막 7일에 사건이 있는 ID만 고정한다.
  이후 자료나 API로 대여소를 고르지 않는다.
- 고정 평균은 `(학습 건수 합+0.5)/(유효 학습 시간 수+1)`이다.
  달력 평균은 `(요일·시각별 건수 합+α×고정 평균)/(해당 학습 시간 수+α)`다. 양수 하한은 1e-6이다.
- α는 2월 deviance만으로 선택하고, 3월 평가 전 모델 파일과 선택값을 저장한다. 이후 재적합하지 않는다.
- 입력은 대여소 ID와 알려진 요일·시각이다. 출력은 해당 정시부터 다음 1시간의 기록 대여·반납 기대 건수다.
  최근 거래·API 입력·그래프·기존 가중치·복원 재고·날씨를 넣지 않는다.
- 학습한 두 모델을 dislab에 저장하고, 파일 해시와 다시 불러온 예측의 일치를 확인한다.

주 지표는 `100×(고정 평균 deviance−달력 deviance)/고정 평균 deviance`다.
도시 전체의 같은 날짜를 동기화한 3일·7일 이동 블록 부트스트랩을 각 2,000회, seed20261031로 수행한다.
빈 날짜를 지우지 않고 3월 달력 위에서 일별 손실 합·평가 칸수를 함께 재표집한다.

## 3. 결과

**미실행.** 적격 대여소 500개·내부 선택 14일·보류 21일·평가 칸 100,000개와 각 블록 유효 복제 1,900회를 충족하고,
두 95% 구간 하한이 모두 1%를 넘으면 지지한다. 두 상한이 모두 1% 이하면 지지하지 않음, 나머지는 불확실이다.
1%는 사전 연구 기준이며 현장 허용 오차가 아니다.

대여/반납별 deviance·MAE, 학습 건수의 90백분위(최소 1) 이상인 정답에서의 MAE는 보조 보고다.
주 판정을 보조 결과로 바꾸지 않는다. α 선택 불확실성은 블록 구간에 포함하지 않는다.

이 기간은 기존 연구에서 이미 요약된 회고 자료다. 완전히 미열람인 독립 시험이라고 부르지 않는다.
기록 누락·운영 상태 미확인·한 계절 내부 보류·낮 시간과 반복 대여소 선택이 일반화를 제한한다.
거래 기록의 예측이 API 재고·실제 이용 가능 상태의 예측과 같은 것은 아니다.

다음 행동은 이 계획과 Draft PR을 게시한 뒤 구현·검사를 완료하고, dislab에서 학습·내부 평가하는 것이다.
그 결과로 기준선과 남은 시간 구조를 정리하며 GCN·Flow Matching 채택은 별도 가설로 남긴다.
