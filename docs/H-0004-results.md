# H-0004 결과: 과거 이력으로 학습한 첫 거래 예측 기준선

[가설 PR #8](https://github.com/sijoon-sung/KT-X-AI-/pull/8)과 [사전 계획](H-0004-historical-calendar.md)에 따른 결과다.
[자료 계약](training-validation-contract.md)을 준수해 다운로드 이력만 사용했다. API 학습·튜닝·선택·외부 검증은 하지 않았다.

## 1. 가설

요일·시간대 평활 평균이 대여소별 고정 평균보다 이후 기록 대여·반납 건수의 평균 Poisson deviance를 1% 넘게 줄일 것이다.
자료·복제 충분성 조건과 3일·7일 도시 날짜 블록 95% 구간 하한 모두 >1%라는 기준을 사전에 동결했다.
기준점 1%는 사전 연구 기준이며 현장 허용 오차가 아니다.
이는 평균 예측의 비교다. 포아송 분포 적합·미충족 수요·실측 재고·결합 시나리오의 검증이 아니다.

## 2. 실험

### 자료와 전처리

다운로드 원본의 월별 인코딩·원본 바이트 해시·필수 열·실제 시각을 확인했다.
월 불일치·24시간 이상/역전 거래와 완전 중복을 사전 규칙대로 처리했으며, 짧은 재대여나 큰 시간별 건수를 임의로 합치거나 자르지 않았다.

|---|---|
| 원본 행 | 9,320,018 |
| 열 수 오류 | 0 |
| 필수 키 누락 | 0 |
| 실제 시각 파싱 불가 | 0 |

원본 전체 유지 건수와 학습에 사용한 관측 칸 수는 다르다.
학습 후보 기간의 원본 월파일·월 안쪽 날짜·07~21시·도시 공통 기록 시간만 사용했다.
대여소는 학습 거래/날짜/초기·말기 관측 조건만으로 고정해 1,192개를 포함했다.
전체 원본 ID 1,425개 중 233개는 사전 학습 기준 밖이었다.

**0의 의미:** 적격 시간 안의 0은 원본에 적격 사건이 없다는 기록 건수다.
실제 거래0·정상 운영·대여소별 수집 완전성을 독립 검증한 값이 아니다.
빠진 월·불명확한 시간은 NaN 마스크로 남겼다. 운영 로그가 없는 기록 범위 가정이 결과의 한계다.

|---|---|---|---|---|

### 학습·선택·모델 저장

고정 평균 `(합계+0.5)/(학습 시간 수+1)`과 요일×시각 평활 평균 `(그룹 합계+α×고정 평균)/(그룹 시간 수+α)`를 학습했다.
최근 거래·복원 재고·API·그래프·기존 가중치는 입력하지 않았다. α만 과거 2월 내부 선택에서 정했다.
3월 점수 계산 전에 두 모델과 선택값·파일 해시를 저장했으며 이후 재적합하지 않았다.

| α 후보 | 2월 평균 deviance |
|---|---|
| 1 | 1.08964564 |
| 4 | 1.07356313 |
| 16 | 1.07229120 |
| 64 | 1.10781843 |

선택된 α는 **16**다. 모델은 dislab의 비공개 `artifacts/constant.npz`, `calendar.npz`에 저장했다.
계수와 대여소 ID 배열을 다시 읽어 원래 값과 정확히 같은지 확인했다.
저장 모델을 실제 예측 명령으로 다시 불러와 범위 안의 예측 두 값이 유한·비음수인지도 확인했다.
가중치 파일·개별 예측·원본 거래는 공개하지 않고 [실행 manifest](../research/runs/H-0004-20261031-historical/manifest.json)에 해시를 남겼다.

두 모델은 학습 대여소의 07~21시 정시를 입력받아 **다음 1시간의 적격 기록 대여·반납 기대 건수**를 낸다.
범위 밖 시각·미학습 대여소는 오류로 알린다. 재고·잠재 수요·서비스 전체 시간의 모델은 아니다.

### 해석과 다음 행동

이번 자료·평가 범위에서 달력 패턴을 학습한 기준선을 후속 비교의 출발점으로 채택한다.
이는 최종 모델·포아송 분포·API 재고 검증의 채택이 아니다.

다음에는 같은 과거 이력의 정답·정보 시점을 유지하면서 최근 시간 이력과 수준 변화에 어떤 추가 가치가 있는지
작은 대조 실험을 새 가설로 설계한다. 분포 표현·공간 관계·결합 시나리오는 각각 다른 질문이다.
GCN·Flow Matching을 한 번에 결합하거나 이 평균 점수로 필요성을 확정하지 않는다.
API는 이후 모델·입력 생성·평가 규칙을 고정한 뒤 외부 검증에만 사용한다.

**한계:** 낮 시간·반복 학습 대여소·원본 기록 범위·거래 기간 제외에 한정한다.
누락과 운영 변경의 완전한 로그가 없고, 시계는 KST 조건부 해석이다.
3월은 기존 연구에서 이미 요약된 회고 내부 보류 기간이며 미열람 외부 시험이 아니다.
부트스트랩은 선택된 α와 대여소에 조건부이고 모형 선택의 불확실성을 포함하지 않는다.
이 모델은 평균 건수 기준선으로, 확률 보정·꼬리·결합 의존성과 API 재고의 신뢰성 검증은 남아 있다.
