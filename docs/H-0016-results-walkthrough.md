# H-0016 · 예측에서 재배치 동선까지 실제 결과 둘러보기

## 가설

사용자가 실제 관측→고정 예측→미래 정답→수량→방문 순서를 따라가면서 관측된 성능과 가정에 따른 계획을 구분할 수 있는 결과 화면을 만든다.
H16은 모델 우월성이나 현장 재배치 효과 가설이 아닌 연결·표시 계약의 기능 검증이다.
학습 전용 자료 계약과 H13/H14/H15의 동결 계획·판정은 바꾸지 않는다.
[Draft PR23](https://github.com/sijoon-sung/KT-X-AI-/pull/23)에 계획·해시를 `12a9b3b92778cad868eae032cac07726227ec07f`로 먼저 게시했다.

## 실험

### 실제 관측과 예측 결과

H13의 2026-10-31 **21:30 관측 → 21:31:11 수집기 기준 예측 발행 확인 → 21:40 미래 관측**을 그대로 읽는다.
기존 발행 파일·현재/미래 스냅샷·원래 채점 결과를 해시로 고정하고, dislab CPU에서 1,296개 대응과 모든 원래 점수를 재현했다.
모델 재학습·새 추론·새 타슈 API 수집·모형 선택·확률 보정은 하지 않았다.
처리는 `7536ab180f3a42a54e33f725f07172476b376613`에서 실행했다. 미래 정답은 그림자계획을 봉인한 다음에만 열었다.

화면의 위치도·검색 표·선택 대여소에서 현재 대수, 모델별 중앙값, 90% 범위, 0대 확률, 미래 실측과 절대 오차를 확인한다.
GCN+FM·GCN+Poisson·현재유지 등 보기 전환은 비교용이며 이미 계산한 그림자계획을 다시 선택하지 않는다.
이 한 회차의 수량 MAE 약0.231대와 공식 9월 전체 평가의 약0.212대를 별도로 표시한다.
원래 H13의 학습 위치 위반·시계 차이와 공식 평가 판정은 원래 PR20 기록으로 보존한다.

### 실제 대여소를 쓰는 그림자계획

미래 관측을 읽기 전에 고정 규칙으로 후보를 고른다. 전체128 terminal 시나리오와 현재 재고가3대 이상인 공급 후보에서
현재 재고 최대(동률ID)의 anchor와 가장 가까운 다른 공급1곳, 현재2대 미만의 가까운 배치3곳을 쓴다.
이것은 한 회차의 운영 후보 제한이며 학습 대여소나 모형·분포 선택이 아니다.

**차량1대·적재6대·시작적재0대·목표재고2대·작업시간0.1분/대·배치허용2대·anchor 출발/복귀는 모두 가정**이다.
허용 주차공간·실제 거점·현장 자전거 상태를 확인한 결과가 아니다.
[OSRM 원문 Table/Route](https://project-osrm.org/docs/v5.24.0/api/)에 따라 실제 좌표의 방향별 도로시간과 경로를 조회했다.
이는 현재 OSM car 추정이며 당시 교통·실제 주행시간·차량 높이/중량/진입 제한을 검증하지 않았다.
실패하면 막힘을 보존하도록 했고 임의 직선 시간을 대신 넣지 않는다.

H15 수량MILP→적재·시간·수거 선행 경로를 연결한다. H13 stationwise CFM의 저장 입자를 쓰며 H14가 학습한 공동분포로 부르지 않는다.
같은 미래 관측을 가상 이동의 정답으로 채점하지 않고 현장 효과는 null로 남긴다.
원본 API·개별 예측·개별 작업표는 공개 저장소가 아닌 비공개 결과 묶음에만 보관하며 로컬 표시 서버로 읽는다.

## 결과

**기능 인수 판정 supported, 원격 검사13개·실패0, 브라우저 정상 상호작용 검사10개 통과**다.
이 판정은 예측의 추가 개선이나 운영 효율 향상을 의미하지 않는다.

| 실제 대여소 기반 그림자계획 | 수거2곳·배치3곳, 총4대 이동, 방문5곳 |

| 도로시간·geometry 조회 | 성공; 원응답 해시를 비공개 묶음에 연결 |

브라우저에서 결과 로드, 표본1296 표시, 실제 명칭, 단계 전환, 검색, 모델 전환, 동선 선택에 따른 적재,
데스크톱/모바일 가로 넘침 없음, 예외 없음까지 확인했다. 화면 PNG는 비공개 로컬 산출물로 보존한다.
기존8768 서버 재시작은 자동 승인 검토에서 거부되어 그대로 유지하고 새 결과를8769에서 제공했다.
추가적인 자료 부재 오류 주입·브라우저 재실행 명령도 자동 검토에서 거부되어 미실행이다. 이를 통과한 검사로 세지 않는다.
자료 부재 시 서버503/화면 오류·대체값 없음 경로는 코드 검토로 확인하며 추후 별도 오류상황 브라우저 검증 대상으로 남긴다.

### 화면과 다음 행동

로컬 결과 화면은 `http://127.0.0.1:8769/results`다. **전체 과정 재생**으로 관측·발행·실측·계획·한계를 순서대로 본다.
실제 대여소를 눌러 비교하고, 이름/ID 검색·보기 모델 전환·동선 재생·요약 내려받기를 제공한다.
이전8768 예측 화면과 별도 주차 방향 프로젝트는 유지한다.

```text
python research_code/results_preview.py --bundle PRIVATE_VERIFIED_BUNDLE.json --port 8769
```

이 표시 서버는 loopback의 고정 파일만 제공한다. 학습·추론·통계·수량/경로를 로컬에서 계산하지 않는다.
독립 재현 시 비공개 입력을 준비한 뒤 `results_walkthrough.py`를 dislab에서 실행한다. 공개 파일에 원본이나 접속 정보를 넣지 않는다.

다음 운영 연구는 실제 도착시간의30/60분 예측, 확인된 차량·거점·주차·작업시간, 다차량 제약, 행동/취소/비용 로그를 갖추는 순서다.
이를 확보하기 전까지 현장 절감이나 RL 정책 성능을 주장하지 않는다. 새 실험은 새 가설·사전 Draft PR로 분리한다.
