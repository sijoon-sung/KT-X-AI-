# H-0023: 고정 특징과 모델 비교

## 가설

현재 GCN이 동일한 자료·예산의 비그래프 MLP와 XGBoost보다 과거 거래 건수를 더 잘 예측하는지 검증한다. 주가설은 2월에서 선택한 비그래프 대조군 대비 3월 deviance 1% 감소와 두 블록 구간의 양수 하한이다. 특징별 기여와 FM의 추가 효과는 따로 판정한다.

## 실험

새 특징을 추가하지 않는다. Full, 이웃 전체 제거, 이웃 대여소 섞기, 기상 제거, 명시적 달력·10분 위치 제거, 최근 흐름 제거, 주간 임베딩 제거, 서울 사전학습 제거를 같은 표본·16epoch·두 시드로 다시 학습한다. 시간대 prior와 XGBoost도 비교한다. Full에만 FM을 다시 학습하며 기존 H13/H22도 고정 가중치 참고값으로 재평가한다.

과거 이력에서 2026년 2월 전까지 학습하고, 2월에서 checkpoint를 선택한다. 3월의 같은 262,144개 대여소·시각과 그중 32,768개의 분포 평가 표본을 사용한다. 3월은 이미 사용한 자료다. 재고 정답이 없으므로 이 점수를 재고 정확도라고 부르지 않는다. 이번 실험에서는 API를 열지 않는다.

입력 해시·모델·학습 예산·지표·불확실성은 [동결 계획](../research/hypotheses/H-0023.json)에 고정한다. 연산은 dislab에서만 실행한다. 전역 최고 모델을 증명하는 실험이나 실측 재배치 효과 평가가 아니다.

## 결과

dislab에서 실제 학습·추론·통계 분석을353.7초에 완료했다. 주가설은 **지지하지 않음**이다. [전체 표·그래프·동시 구간](../research/runs/H-0023-20261110-feature-model-audit/results.md), [실행 manifest](../research/runs/H-0023-20261110-feature-model-audit/manifest.json), [시드별 점수·추적값](../research/runs/H-0023-20261110-feature-model-audit/summary.json)을 보존했다.

기상 효과의7일 동시 구간은 약[0.002%,4.281%]로 하한이0에 가깝다. 한 시기만의 결과이며 실시간 기상 연결의 효과를 검증한 것은 아니다. 올바른 OD 이웃을 무작위 대여소 이웃으로 바꾼 구성도 full보다 낮은 deviance를 보여, 현재 고정 OD 관계가 성능 개선의 핵심이라는 주장을 뒷받침하지 않았다.

기본 H13과 기존 관리자는 유지했다. 이번 시험은 실제 거래 건수에 대한 비교이며 재고·품절 정답은 아니다. 특징 추가와 크기 확대를 계속하기보다 기상을 유지하고, encoder의 이웃·사전학습 경로와 FM 출력이 필요한지 별도 검증한 후 단순화한다. FM을 개선했다고 발표할 근거는 이번에도 얻지 못했다.
