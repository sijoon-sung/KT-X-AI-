# 아키텍처 검증 결과: H-0002

결론: **지지하지 않음**. 판정은 소형 API 재고 적응 모형의 30분 뒤 관측 0대 확률에 한정한다.
기존 Transit-CFM 전체의 재현이나 모든 Flow Matching 모형에 대한 판정이 아니다.

## 코드와 데이터 검토

[코드 검토](architecture-audit.md)에서 기존 거래량 정답과 API 재고의 차이,
사후 복원 재고·전체 OD의 미래 정보 위험, 실측 날씨 입력과 0 초기값 경로의 해석 문제를 기록했다.
생성 ODE의 시간은 물리적 자전거 이동 시간이 아니며, 입력 변경에 대한 예측 차이는 정책의 인과 효과가 아니다.

원본 88개 파일과 재구축 패널·요청 시각의 일치를 확인했다.
H-0001의 관측 간격 비교는 평균 절대차 1.24%p로 5%p 초과 가설을 지지하지 않았다.
그 결과를 30분 수집의 충분성이나 실제 연속 품절의 정답으로 해석하지 않는다.

## 동결 계획과 실제 비교

H-0002 동결 커밋은 `d2e663218f52e41730c5bf5494c2114cd7e0ab6d`다.
구현·실행 코드 커밋은 `ddb1af2f9a1296760a898832e94c6d9ec3a3fd26`다. 계획·코드를 PR #3에 게시한 뒤 실행했다.

- 학습: 2026-09-18~10-15, 검증: 10-16~10-22, 시험: 10-23~10-29. 한국 시간 조건부 해석이다.
- 첫날 좌표와 학습 관측률만으로 고른 대여소 1,369개.
- 시험 요청 시각 167개, 유효 대여소·시각 228,456개.
  그 중 현재 양수 표본 119,276개가 주 평가 대상이다.
- 각 모델 600 update, 폭 32·잔차 블록 2개, 시드 17·29·43. 검증 점수로 checkpoint만 선택했다.
- 시험 점수는 날짜별 평균을 다시 평균하고, 학습 시드 점수의 평균을 보고한다. 예측 앙상블 점수가 아니다.
- CFM은 정수 재고의 dequantization과 Gaussian 표본으로 확률을 계산했다. 검증 64개·시험 128개, Euler 12 step이다.
- 실측 장치: NVIDIA GeForce RTX 3080, PyTorch 2.7.1+cu118.
  PyTorch가 기록한 최대 할당 메모리는 47.0 MiB다.

## 결과

Brier score는 낮을수록 좋다. 현재 양수인 곳의 미래 0대 위험이 사전 지정한 주 지표다.
현재 0대와 전체 점수는 보조 지표다. 서로 다른 분모의 점수를 같은 현상으로 취급하지 않는다.

| 모형 | 현재 양수 Brier | 현재 0대 Brier | 전체 Brier | 파라미터 | 전체 시험 추론 초/시드 |
|---|---:|---:|---:|---:|---:|
| 현재 상태 유지 | 0.102642 | 0.104786 | 0.103613 | 해당 없음 | 미측정 |
| 학습 기간 상태별 빈도 | 0.088490 | 0.087423 | 0.087937 | 해당 없음 | 미측정 |
| 자기 이력 직접 분류기 | 0.079564 | 0.088153 | 0.083689 | 22,601 | 0.06 |
| 좌표 그래프 직접 분류기 | 0.078826 | 0.088270 | 0.083351 | 22,601 | 0.07 |
| 연결을 섞은 그래프 분류기 | 0.079817 | 0.089420 | 0.084412 | 22,601 | 0.07 |
| 그래프 CFM | 0.082581 | 0.122621 | 0.101592 | 34,537 | 28.99 |

- 자기 이력 직접 분류기 대비 CFM 상대 개선: -3.793%. 점수차(대조군−CFM) 95% 구간: -0.003685~-0.002583.
- 좌표 그래프 직접 분류기 대비 CFM 상대 개선: -4.764%. 점수차(대조군−CFM) 95% 구간: -0.004574~-0.002830.

사전 지지 조건은 두 대조군 각각에 대해 2% 이상 개선하고, 날짜 블록 구간 하한이 0 초과인 것이다.
CFM의 MC 보정 보조 Brier는 0.081973다. 주 판정은 계획대로 통상 plug-in score를 사용했다.
구간은 7개 시험 날짜의 2일 이동 블록에 근거하며 연중 일반화나 모든 대여소의 보장을 뜻하지 않는다.

## 보조 진단

- 좌표 그래프 분류기의 자기 이력 직접 분류기 대비 상대 개선은 0.927%, 날짜 점수차 구간은 -0.000076~0.001226. 이 구간은 주 판정과 분리한 보조 분석이다.
- 좌표 그래프 분류기의 연결을 섞은 그래프 분류기 대비 상대 개선은 1.241%, 날짜 점수차 구간은 -0.000106~0.001638. 이 구간은 주 판정과 분리한 보조 분석이다.

- 시드 17: CFM 표본 평균 재고 MAE 0.575, 표본 중앙값 0.467, 0 초기값 경로 0.462, 현재 재고 유지 0.372대. 보조 지표이며 주 가설 판정에 쓰지 않았다.
- 시드 29: CFM 표본 평균 재고 MAE 0.635, 표본 중앙값 0.497, 0 초기값 경로 0.497, 현재 재고 유지 0.372대. 보조 지표이며 주 가설 판정에 쓰지 않았다.
- 시드 43: CFM 표본 평균 재고 MAE 0.659, 표본 중앙값 0.505, 0 초기값 경로 0.498, 현재 재고 유지 0.372대. 보조 지표이며 주 가설 판정에 쓰지 않았다.

## 계산 중 실패와 재실행

로컬 첫 실행은 CFM의 첫 검증에서 GPU 메모리 한도를 넘어 중단됐다.
사전에 허용한 대로 생성 chunk를 16에서 4로 줄인 실행도 GPU 연산 오류로 종료됐다.
후속 사용자 지시에 따라 계산을 dislab으로 옮겨 동일 코드와 전체 비교를 다시 실행했다.
로컬에서 더 실험하지 않았으며, 두 중단 실행과 완료된 dislab 실행 중 좋은 점수를 골라 보고하지 않았다.
모형·학습량·표본 총수·기간·판정 기준은 유지했다. 계산 장소·GPU·CUDA·NumPy 환경 변경은 실행 기록에 명시했다.

## 해석과 다음 판단

이 비교는 하나의 작은 설정에 대한 증거다. 최종 아키텍처를 선정하는 비교로 확대하지 않는다.
자기 이력 직접 예측은 재현 가능한 기준선으로 보존한다.
이후에는 예측할 상태·관측 과정·시간과 공간 의존성·확률 표현을 먼저 정하고,
계수형 모형, 과정 기반 모형, 결합 시나리오 생성 모형을 문헌과 자료 조건에 따라 비교한다.
GCN·포아송·Flow Matching은 각 역할과 사용 조건을 검토한 뒤 구체적인 후보에 넣는다.
H-0002는 결합 분포·여러 시점의 궤적·다른 사전분포·이산 Flow Matching 전체를 시험한 결과가 아니다.
새 비교에서는 이 결과를 보존하고 질문·예산·평가 기준을 별도 PR에 동결한다.

대중교통·날씨·서울 전이·원래 6층 대형 구조·실제 재배치 효과는 이번에 검증하지 않았다.
시험 기간은 H-0001에서 이미 관측 요약에 사용했으며, 재실행에서도 같은 기간을 반복 평가했다.
완전히 미열람인 새 시험이라고 부르지 않는다. 실제 사용 전에는 새 수집 기간에서 전향 평가가 필요하다.
