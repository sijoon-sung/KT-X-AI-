# H22 GCN·Flow Matching

과거 완료 대여·반납 건수로 학습하는 10분 재고 예측 모델이다. 현재 API 재고와 직전 변화량은 추론 입력으로만 사용한다. 2·3월 거래 건수와 9월 실측 재고 평가는 구분한다.

GCN 폭1280·은닉층4개, 420→256→64의 주간 encoder, 과거OD 그래프를 사용한다. FM 조건망은 1280차원3개층에서128차원으로 압축하고 대여소별 한 번 계산한다. 128차원 속도장은128개 표본을16단계 Heun으로 생성한다. 독립 Gaussian coupling이며 최적수송 결합이나 도시 전체 공동분포는 아니다.

시드11·29의 GCN과FM을 모두 불러온다. 목표 가중치 크기는 합계90–110MB다. 체크포인트별 실제 매개변수·바이트·SHA256은 릴리즈 `model-publication.json`에 기록한다. 약200MB의 과거 정적 특징표는 별도다.

학습: 2024년8월~2026년1월. 선택: 2026년2월의 고정 표본. 과거 비교: 2026년3월16384개 노출. 재고 평가: 기존에 노출된2026년9월API 수집본. API의 학습·튜닝·보정·선택은 금지한다. H13의 과거 이력 encoder에서 초기화하며 새 GCN·FM 층을 학습한다. 모든 배포 텐서의 초기값 대비 갱신 여부를 검사한다.

결과는 `docs/H-0022-100mb-model.md`에서 갱신한다. 파일 크기 증가가 성능 향상을 뜻하지 않는다. 재배치 차량·주차·상하차는 운영 가정이며 현장 효과는 별도 측정이 필요하다.
