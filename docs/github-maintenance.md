# 저장소 구성과 이전 작업

기본 브랜치에서 README, 홈페이지, 모델 실행 도구, 재배치 코드와 실험 기록을 함께 제공한다. 모델 가중치는 GitHub Releases에서 받는다. 원본API·거래·접속정보는 저장소에 포함하지 않는다.

| 위치 | 용도 |
|---|---|
| `index.html`, `assets/` | 기술·평가·재배치 설명 홈페이지 |
| `transport-example.html` | 합성 교통 연계·혼잡별 경로 예시 |
| `runtime/` | 모델 검증·예측·HTTP·재배치 실행 |
| `research_code/` | 버전별 연구 구현 |
| `research/hypotheses/`, `research/runs/` | 사전 계획·실행·결과 |
| `docs/quickstart.md`, `docs/dispatch-runbook.md` | 설치·API·관리자 실행 안내 |

## 가설

브랜치마다 나뉜 실행 경로와 문서를 기본 브랜치로 모으면 실행 파일과 현재 결과를 찾기 쉽다. 새 모델 성능을 주장하는 변경은 아니다.

## 실험

통합 원본은 `github-integration.json`에 원PR·커밋으로 기록한다. 이미 완료한 가설의 계획·수치·실행 환경은 그대로 가져온다. H14의 개선 없음과철회 기록도 포함한다. 원본 브랜치와 PR은 삭제하지 않는다. 이전 홈페이지 브랜치의 실험 모델·출력·분석 스크립트는 현재 실행 경로로 가져오지 않는다.

모든 가져온 연구 파일의 Git blob을 원 커밋과 대조하며 동결 계획·manifest 검사와도 함께 수행한다.

## 결과

검사와 병합 결과는 통합 PR에 기록한다. 통합 완료 후 이전 작업 PR은 원래 기록을 유지한 채 통합 PR에 연결한다. 실제 배포된 차량 운영이나 새 예측 성능을 의미하지 않는다.
