# H-0019 · 관측에서 자동 재배치 계획까지

## 가설

API는 갱신되지만 방문 후보가 과거의5곳에 고정돼 있다. 전체 지원 대여소를 훑어 공급·부족 후보를 자동으로 찾고 수량과 방문 순서를 함께 계산하면 이 제약을 줄일 수 있다. 실제 자원·행동 로그가 없어 현장 효용 가설로 확대하지 않는다.

## 실험

세부 계획은 `research/plans/H-0019-v1.json`에 동결한다. Draft PR을 게시한 뒤 모든 계산을 dislab CPU에서 실행한다. 고정 H13 예측과 현재 API는 계획 입력이며 가중치·분포·임계값을 API로 선택하지 않는다. 0대 대여소의 잠재 수요는 관측되지 않았다.

전체 지원 대여소를 스캔하고 최대29곳의 공급/부족 후보에 대해 정수 수량과 최대6회 방문을 탐색한다. 출발·복귀, 중간 적재, 공급지 안전 재고와 작업시간을 검사한다. 10분 예측의 유효 시점까지 남은 시간보다 긴 계획은 발행하지 않는다. 도로 시간은 [OSRM 추정](https://project-osrm.org/docs/v5.24.0/api/)이며 실제 교통·차량 진입 조건은 미확인이다.

자동 후보와 제한된 빔 탐색은 도시 전체 최적해를 보장하지 않는다. 기존5곳 경로·2곳 이동·이동 없음의 실행 가능한 기준안을 보존한다. 주변부에 남은 미처리 대여소도 보고한다. 실제 배차는 하지 않는다.

## 결과

아직 미실행. 사전 Draft PR과 실행 코드 게시 후3개 관측 상태와 합성 소규모 완전 탐색을 비교한다. 모델 기반 부족/0대 위험 대리값과 실제 결품 예방 효과를 구분한다.
