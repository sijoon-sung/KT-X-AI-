# 연구 방향 결정 기록

기준일: 2026-10-31. [연구 프로그램](research-program.md)의 큰 선택을 추적한다.
`확정`은 현재 작업 원칙, `검토 중`은 아직 모형·실험으로 고정하지 않은 선택이다.

| 항목 | 상태 | 현재 판단·근거 | 다음에 필요한 근거 |
|---|---|---|---|
| 연구의 큰 주제 | 확정 | 관측 제약하의 공공자전거 미래 가용 상태와 불확실성 모델링 | 사용자 안내·운영 판단별 구체적 출력 요구 정리 |
| 직접 정답 | 확정 | 현재 자료에서는 API `parking_count` 응답. 거래·잠재 수요·정책 효과의 정답과 구분 | 시간대·갱신 지연·현장 상태를 검증할 추가 자료 |
| 연구 진행 방식 | 확정 | 문제→관측/과정→의존성→확률 출력→모형군→아키텍처 순서 | 각 선택에 연결된 문헌·자료 진단·반증 조건 |
| 계산과 기록 | 확정 | 연산은 dislab. 가설별 Draft PR과 실험 전 동결, 실패·불확실 결과 보존 | 새 실험마다 동일하게 적용 |
| 과거 H-0002의 위치 | 확정 | 한 소형 설정의 30분 관측 0대 비교. 최종 모형군 선택으로 확대하지 않음 | 다른 가정·출력·예산을 비교하려면 새 가설과 평가 계획 |
| 주변 분포와 결합 분포 중 필요한 출력 | 검토 중 | 이용자 도착 시점과 여러 대여소 운영 판단의 요구가 다를 수 있음 | 사용 상황, 동시 사건·시간 경로가 의사결정에 주는 가치 |
| 관측 직접 예측과 과정 기반 모형 | 검토 중 | API로 직접 관측 예측 가능. 과정별 분리는 추가 자료 또는 가정이 필요 | 거래·운영 로그 접근성, 가정 아래 식별성·민감도 |
| 포아송의 역할과 관측 분포 | 검토 중 | 사건률과 재고 평균을 구분. 조건부 분산·0 구조에 맞는 분포를 선택 | 학습 구간 중심의 조건부 변화·분산·0 구조 진단 |
| GCN 채택과 그래프 의미 | 검토 중 | 거리·이동·기능·학습 의존성은 서로 다른 관계 | 자기 이력 대비 가치, 자료 누출 방지, 관계 안정성 |
| Flow Matching 채택과 표현 | 검토 중 | 결합 시나리오 생성 후보. 사전분포·정수 표현·평가가 미정 | 단순 결합 모형 대비 가치, 주변/결합 보정, 계산 비용 |
| 최종 네트워크·크기·분포 head | 미정 | 위 선택을 정리하기 전에는 확정하지 않음 | 후보 모형군을 비교할 이유와 최소 가설 |
| 정책 최적화·인과 효과 | 미정 | 예측 모형의 입력 변경만으로 효과를 입증할 수 없음 | 운영 조치·제약·결과 로그와 식별/현장 검증 설계 |

## 다음 작업의 경계

다음에는 문헌의 관측·분포 가정과 현재 자료를 대조해 **먼저 설명해야 할 데이터 구조**를 좁힌다.
바로 GCN·CFM·포아송을 결합한 큰 모형을 학습하지 않는다.
자료 진단도 실제 가설 검증으로 진행할 때 새 ID·Draft PR·동결 계획을 먼저 만든다.
현재 H-0003이나 추가 학습 실행은 시작하지 않았다.

결정이 바뀌면 새 근거·이유·연결 PR을 남긴다.
과거 동결 가설은 바꾸지 않고, 현재 방향의 변경과 기존 실험 기록을 함께 보존한다.
