# H-0026: 예측 결과를 설명하는 운영 도우미

## 가설

소형 언어 모델이 기존 예측·재배치 결과를 읽고 비전공자에게 짧은 한국어로 설명할 수 있는지 확인한다. 질문은 어디가 부족한지, 몇 대를 옮길지, 어떤 순서로 갈지를 중심으로 한다. 예측 모델은 H13으로 유지한다.

## 실험

계획·미실행. Qwen3-1.7B를 dislab에서 실행하고, 합성 질문 10개와 자료·오류 처리 6개를 검사한다. 실제 LLM 생성과 자료 기반 기본 문장은 구분한다. 허용한 예측·계획 필드만 문맥으로 전달하며 API 키·원시 응답을 넘기지 않는다. 현재 자료가 없으면 기록 또는 예시임을 표시한다.

## 결과

미실행. 모델 설치·실제 생성·CLI/API·화면을 연결한 뒤 관측한 답변과 검사 결과를 기록한다. 답변 기능이 예측 정확도나 배차 효과를 높였다고 주장하지 않는다.
