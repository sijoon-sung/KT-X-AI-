# H-0026: 예측 결과를 설명하는 운영 도우미

## 가설

소형 언어 모델이 기존 예측·재배치 결과를 읽고 비전공자에게 짧은 한국어로 설명할 수 있는지 확인한다. 질문은 어디가 부족한지, 몇 대를 옮길지, 어떤 순서로 갈지를 중심으로 한다. 예측 모델은 H13으로 유지한다.

## 실험

실험 전 Draft [PR38](https://github.com/sijoon-sung/KT-X-AI-/pull/38)과 동결 계획을 게시했다. Qwen3-1.7B의 revision `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`를 고정해 dislab RTX3080에서 FP16으로 실행했다. 별도 가상환경에 Transformers 4.57.1을 설치했고 기존 Torch 2.7.1+cu118·H13 가중치는 바꾸지 않았다.

개발 확인 3회와 정상 질문 10개·자료 및 오류 검사 6개의 고정 시험을 보존했다. 알려진 합성 예시를 이용한 기능 시험이며 한국어 능력이나 사용자 이해도의 독립 시험은 아니다. API를 열거나 학습·튜닝하지 않았다. 근거 ID는 서버가 부여한다. 모델이 스스로 사실을 검증했다는 뜻은 아니다.

## 결과

**주가설은 지지되지 않았다(`not_supported`).** 첫 고정 시험의 실제 LLM 답변은 10개 중 7개로 사전 기준 8개에 미달했다. 나머지 3개는 자료의 문장을 표시했다. 9개는 정해 둔 답안 패턴에 맞았지만, “6대를 싣는 계획”에 현재 재고인 “12대”를 답한 오류가 있었다. 숫자 허용 목록만으로 수량의 의미를 보장할 수 없었다.

6개 기능 검사 중 자동 통과는 4개였다. 기록 여부·미충족 인원 질문의 답변은 각각 “현재 실시간으로 받은 자료가 없습니다”, “자료에 명시되지 않았습니다”였지만 고정한 정규식에 맞지 않아 실패했다. 이 검사를 사후에 통과로 바꾸지 않았다. 원문과 판정을 모두 보존했다. 첫 실행은 35.87초였다.

수정 뒤 같은 시험을 다시 실행한 기록도 별도로 남겼다. 답안 패턴은 10개가 맞았고 실제 LLM 답변은 여전히 7개였다. 이는 결과를 본 뒤의 구현 확인이며 주가설의 재검증 성공으로 사용하지 않는다.

### 구현 보완

- 싣기·내려놓기 질문에는 현재 재고를 섞지 않고 해당 방문의 계획 수량만 전달한다. 자료 시각의 숫자도 수량의 허용 근거로 쓰지 않는다.
- 방문지의 누락·순서 변경, 단일 방문의 다른 수량, 0대 대여소를 빠뜨린 답변은 원래 자료의 문장으로 바꾼다.
- H13의 실제 합성 예측 출력과 연결한 첫 질문에서 모든 대여소를 답한 오류, 필터 수정 뒤 “없는 대여소가 없다”고 답한 오류도 보존했다. 후속 보완은 해당 대여소 이름이 빠지면 답변을 거부한다.
- 실제 기록 시연의 긴 동선에서 방문 한 곳을 빠뜨리는 사례도 확인해 전체 방문지 검사를 추가했다. 임의 한국어 문장의 모든 의미를 검증하는 장치는 아니다.

### 제공 기능

`runtime/operator_assistant.py`는 고정 H13 예측 요약과 기존 재배치 계획을 읽는 CLI·HTTP 서버다. `runtime/assistant_web/`은 “몇 대?”, “어떤 순서?”를 묻는 화면이다. 로컬 `assistant_proxy.py`는 HTTP 요청을 기존 SSH 연결로 전달한다. 답변·자료 요약은 dislab에서 수행하며 SSH나 방화벽 설정은 바꾸지 않았다.

실제 LLM은 1,720,574,976개 파라미터이며 safetensors 파일 합계는 4,063,515,592바이트다. 이는 H13 예측 모델의 크기와 별개다. 모델 파일 해시·질문·답변·실행 시간·GPU 사용량은 [실행 기록](../research/runs/H-0026-20261110-operator-llm/)에 있다. 설치·실행은 [빠른 안내](quickstart-llm.md), 공모전 내용은 [발표와 도입 계획](competition-guide.md)에 정리했다.

H13 합성 예측 연결과 H21 기록 계획 시연은 다른 상황이다. 두 결과를 같은 회차로 합치지 않았다. 새 예측 정확도·실제 배차·실제 사용자 이해도 향상을 측정한 결과는 없다. 원래 예측과 계획표가 기준이며, 설명 문장이 그 값을 바꾸지 않는다.

이 기능은 공모전에서 계산 결과를 쉽게 읽는 데 사용한다. 현장 도입은 담당자의 수량·순서 확인과 함께 시험한다.
