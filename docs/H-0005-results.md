# H-0005 결과: 과거 거래 흐름을 9월 미래 재고로 연결

[PR #10](https://github.com/sijoon-sung/KT-X-AI-/pull/10), [사전 계획](H-0005-history-to-stock.md),
[아키텍처 아이디어의 역할](architecture-ideas-to-experiments.md)을 연결한다.
이는 최신 자료 계약의 **공식 9월 API 평가**다. 2·3월 재고 정답을 만든 실험이 아니다.

## 1. 가설

과거 이력만으로 학습한 달력 대여·반납률을 비음수 재고 과정에 넣으면,
현재 재고가 양수인 표본의 30분 뒤 관측 0대 Brier를 현재 유지보다 0.005 넘게 줄일 것이다.
자료 충분성과 3일·7일 블록 95% 구간 하한 모두 >0.005를 실험 전에 동결했다.
이 간격은 연구 기준이며 현장 효용이나 실제 품절 비용의 기준은 아니다.

선행연구의 큐 아이디어를 가져오되 과거 실측 재고가 없으므로 노출시간 보정 사건률은 추정하지 않았다.
GCN은 흐름 추정 맥락, FM은 결합 흐름 생성 후보로 남겼으며 이번에는 연결 가정만 비교했다.

## 2. 실험

### 자료·모형·평가 경계

- H-0004에서 저장한 과거 전용 `calendar.npz`와 `constant.npz`를 SHA-256으로 고정했다. 새 학습·재적합은 없다.
- 달력률은 사전 주후보, 고정률은 보조다. 9월 점수로 둘 중 선택하지 않는다.
- 반납을 도착, 대여를 출발 시도로 놓고 0에서 반사하는 연속시간 과정을 사용했다. 물리 용량 상한·재배치·노출시간 보정은 없다.
- 현재 API 재고는 **평가 시작 상태**로만 사용했다. 미래 API는 정답만 제공하며 학습·튜닝·보정·선택에 쓰지 않았다.
- 공식 기간은 9/1 이상~10/1 미만 KST 조건부다. 실제 수집 범위는 **9/17~30**, 정시 07~21시 발행·고정 30분 뒤 예측이다.
- 현재·목표 모두 9월이고 누락은 0으로 채우지 않았다. 10월 관측은 표본·점수에 들어가지 않는다.
- API 요청 시각은 서버 갱신 시각이 아니다. 실제 요청 경과는 1799~1801초였다.

## 3. 결과

**사전 가설 지지.** 현재 양수 Brier는 0.149934 → 0.119369,
절대 감소 0.030565다.
3일 블록95% 구간은 0.020927~0.036069,
7일은 0.025101~0.035048다.
두 하한 모두0.005보다 크고 자료 충분성을 충족했다. 유효 복제는 각2,000회다.

보조 점수에 별도 유의성 판정을 붙이거나 고정률/달력률의 미세한 차이로 모형을 선택하지 않는다.

### 해석·채택 범위

과거 흐름과 현재 상태를 분리해 연결하는 구현은 후속 **확률 예측 대조 기준**으로 보존한다.
전체 재고 예측의 기본 운영 모델로 채택하지 않는다(`adopt_code=false`).
GCN, Poisson 관측 분포의 적합, FM의 결합 생성 능력, 도시 정책 효과 또는 완성 아키텍처의 검증으로 확대하지 않는다.

완료 거래율은 수요·가용 노출시간 보정 사건률이 아니다. 독립·무기억 과정과 과거→9월 이전,
재배치 누락·상한 미모형화·ID 변경·주간/공통 표본 제한이 남는다.
날짜 블록 구간은 과거 계수 추정 불확실성을 포함하지 않는다.
9월은 이전 API 개발·탐색에 노출됐으므로 **미열람 독립 시험이 아니다**. 공식 기간은 유지하고 노출을 공개했다.

### 다음 행동

1. 상태 모듈·현재 유지·평가 코드를 분리된 비교 기준으로 보존한다. 9월 점수에 맞춘 사건률 보정이나 수치 허용오차 조정은 하지 않는다.
2. 공간 정보의 필요성은 **과거 학습 이력에서만** 새 가설로 좁힌다. 학습기간 OD 관계와 자기 대여소/치환 관계를 대조하고, 같은 달력 입력·출력·학습 예산을 둔다. 관계 생성·분할·주 점수를 새 PR에서 먼저 동결한다.
3. 분포·결합 생성 질문은 그다음 별도 비교로 남긴다. 과거 자료의 분포/의존성 근거와 단순 결합 대조군 없이 FM을 필수 모듈로 확정하지 않는다.

위 후속 실험은 이번에 실행하지 않았다. 공식 API는 계속9월이며, 후속 구조·튜닝 선택은 과거 이력 내부에서 끝낸다.

**후속 해석 점검:** [H-0006](H-0006-results.md)은 같은분포의 평균과 MAE에 맞는 중앙값을 구분했다.
평균은 RMSE에서 현재 유지보다 낮았다. 위 평균MAE 악화를 분포 전체 실패로만 해석하지 않는다.
H5의 동결 계획·수치·판정은 그대로 보존하며, H6의 현재유지 대비 중앙값MAE 개선도 확정적이지 않았다.
