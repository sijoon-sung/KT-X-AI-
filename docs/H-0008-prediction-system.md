# H-0008: 공모전용 실제 예측시스템 연결

## 1. 가설

학습된 과거전용 GCN을 서비스로 연결해 기존 고정예측을 재현하고 입력/미래정답 분리 계약을 지킬 수 있다.
성능 우월성보다 작동하는 시스템을 우선하라는 사용자 지시에 따른 공학 인수검증이다.
GCN은 공모전 시연용 기본 경로로 사용하고 달력 참고출력을 함께 보여 준다. H7의 부정결과는 보존한다.

## 2. 실험

기존 체크포인트·그래프·고정률의 해시를 확인하고 실제 GCN forward와 export일치를 검사한다.
새 학습·API튜닝·보정·혼합가중치 탐색은 없다. 과거이력 학습·9월공식평가 계약을 유지한다.
64개 현재상태fixture는 미래값을 보지 않고 결정적으로 선택한다. 확률<=1e-10·평균<=1e-8오차, 분위수정확일치와 기능검사를 요구한다.
서비스는 대여소·시각·현재대수로30분 뒤 대표대수/평균·0대확률·5~95%모형범위를 반환한다.
9월기록재생과수동/현재스냅샷 입력을 지원하고 미래정답 조회는 별도다. 실시간API접속이나운영성능을가장하지않는다.
정시외시점은시간대률을30분고정한시나리오로미검증시간범위를표시한다. 전산계산·검증·서버는dislab,화면은로컬미리보기다.
전체규칙과입력해시는 [동결기록](../research/hypotheses/H-0008.json)·[입력목록](../research/datasets/tashu-prediction-system-H0008-v1.json)에 있다.

## 3. 결과

**supported: 예측 시제품 연결을 채택한다.** 대여소·현재 표시 대수·시각을 받아30분 뒤 재고와0대 확률을 보여 주는 [타슈다음](prediction-system.md)을 구현했다.
GCN을 사용자 요청에 따른 공모전 시연 기본 경로로 사용하며 달력 참고출력을 함께 제공한다.
[H7](H-0007-results.md)의 성능 추가가치 부정판정·`adopt_code=false`는 그대로다. H8의 `adopt_code=true`는 서비스 구현 채택에 한정한다.
