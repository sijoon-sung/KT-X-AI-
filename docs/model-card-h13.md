# H13 고정 모델

GCN 기반 대여·반납 예측과 조건부 Flow Matching으로 10분 후 API 표시 재고 분포를 계산한다. 과거 거래 이력으로 학습한 원본 가중치를 배포한다. 이번 배포에서는 재학습하거나 API로 보정하지 않았다.

## 크기

| 구성 | 파라미터 수 |
|---|---:|
| GCN 예측망 1개, weekly encoder 포함 | 317,122 |
| 위 예측망에 포함된 weekly encoder | 124,352 |
| Flow Matching head 1개 | 67,202 |
| 한 시드의 GCN + FM | 384,324 |
| 두 시드의 FM 예측 경로 | 768,648 |
| 현재 로더 전체: GCN 4개 + FM 2개 | 1,402,892 |

시드는 11과 29다. 현재 로더는 최근 입력이 없는 GCN 기준선 두 개도 함께 로딩한다. 두 시드 FM 경로의 FP32 파라미터는 3,074,592바이트이며, 전체 로딩 파라미터는 5,611,568바이트다. 체크포인트 파일에는 저장 형식의 부가 정보가 있어 실제 파일 크기가 조금 더 크다.

`context.npz`는 200,047,986바이트다. 파라미터가 아니라 과거 이력에서 만든 대여소별 계절 특성·주간 프로필·OD 그래프다. 1,318개 학습 대여소와 4,032개 계절 시간 슬롯을 포함한다. 이 파일과 무결성 검사에 필요한 `time-features.npz`도 묶음에 포함한다. 원본 거래 행과 재고 API 관측은 포함하지 않는다.

## 구조와 출력

- 주간 프로필 encoder: 420 → 256 → 64, SiLU·LayerNorm.
- GCN 예측망: 자기 입력 164차원, 이웃 입력 72차원, 은닉 폭 256. 자기·이웃 선형 결합 뒤 256차원 선형층 두 개, 대여·반납 2차원 양수 평균 출력.
- FM: GCN의 256차원 표현과 예상 건수를 조건으로 로그 건수 잔차의 속도장을 학습. head 폭 128, Heun 16단계.
- 대여소·발행 시각당 128개 IID seed-mixture 표본.
- 재고 표본: `max(0, 현재 재고 + 생성 반납 - 생성 대여)`.
- 포아송과 FM은 별도 경로다. 도시 전체 공동 이동 궤적, RL 정책, 최적 수송 결합을 학습한 모델은 아니다.

## 잠금과 검증

원본 `model-lock.json`의 SHA-256:

```text
767061e696f2b72fd48a14dbd4ea1851921bd3481405f6887e48d28ee8acbe09
```

잠금에 포함된 8개 파일과 필요한 추론 코드의 해시를 검증한다. 원래 체크포인트를 `torch.load(..., weights_only=True)`로 읽고 `strict=True`로 상태 사전을 맞췄다. 전체 파일 목록은 묶음의 `package-manifest.json`, 모델 크기는 `model-info.json`에 들어 있다.

공식 평가: 2026-09-17~30, 1,298개 대여소, 2,458,501쌍, 10분 후 재고. 현재 유지 대비 fairCRPS가 포아송 15.49%, FM 15.22% 감소했다. 중앙값 MAE는 현재 유지 0.212015대, 포아송 0.212039대, FM 0.211982대다. FM fairCRPS는 포아송보다 0.327% 높았다.

9월 자료는 개발 과정에서 반복 사용했다. H13 과거 학습을 로컬에서 수행한 실행 위치 위반과 dislab 전체 평가 전환은 [원 기록](https://github.com/sijoon-sung/KT-X-AI-/blob/hypothesis/H-0021-bulk-rebalancing/docs/H-0013-rolling-api-flow.md)에 보존했다. 이번 파일 묶음·합성 입력 검사는 새 정확도 평가가 아니다.

## 사용 범위

API는 고정 모델의 당시 입력과 별도 미래 평가에 사용한다. API로 학습·튜닝·분포 선택·확률 보정을 하지 않는다. 실행 래퍼의 기본 기상 입력은 **원래 H13 인코더의 결측 표현**이다. 모든 날씨가 0이라는 뜻은 아니며, 실시간 기상 연결이나 54차원 특징을 임의 재정의한 것이 아니다.

0대에서 포기한 이용자, 재배치 행동, 수리·서버 보정은 직접 관측하지 못했다. 새 대여소나 다른 도시의 번호를 임의로 대응하지 않는다. 버스·철도 입력은 아직 이 모델의 학습 특성이 아니다.

학습 자료 출처: 대전교통공사 타슈 대여이력, 서울특별시 따릉이 대여이력(OA-15182), NOAA GHCNh·기상청 과거 관측. 출처·해시·이용 조건은 저장소의 자료 계약과 원본 감사 기록을 따른다. 특성 파일에 포함된 이력 집계는 실측 재고 정답이 아니다. 원본 학습·평가 자료의 라이선스가 코드·가중치와 자동으로 같다고 해석하지 않는다.
