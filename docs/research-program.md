# 큰 연구 방향에서 구체적인 모형으로 좁혀 가기

작성일: 2026-10-31. 상태: 연구 프로그램 초안. 최종 아키텍처는 미정이다.
최신 [자료 계약](training-validation-contract.md)에 따라 **과거 기록으로 학습·내부 검증하고 API는 외부 검증에만 사용**한다.
H-0003의 API 분산·상태 유지 통계를 후속 분포·모형 선택 근거로 사용하던 방향은 종료했다.
근거는 [문헌 비교표](research-evidence-map.md), 현재 선택 상태는 [결정 기록](research-decisions.md)에 모은다.

## 1. 우선 정할 연구의 큰 주제

**불완전한 공공자전거 관측에서 미래 가용 상태의 불확실성을 어떻게 모델링할 것인가?**

이 주제 아래에서 이용자의 도착 시점 가용성, 운영자의 여러 대여소 상태 파악,
추가 자료를 확보한 뒤의 수요·재배치 판단을 검토한다.
특정 신경망 조합을 먼저 완성하지 않는다. 문제·정답·관측 과정·필요한 확률 출력이 정해지면
그 조건을 만족하는 모형군을 비교하고, 그 뒤에 구성요소와 구현을 좁힌다.

지금 확정하는 원칙은 API 관측과 직접 관측하지 못한 대상을 구분하고, 예측 불확실성을 평가하며,
새 가설은 실험 전에 PR에 동결하고, 연산은 dislab에서 수행한다는 것이다.
GCN, 포아송, Flow Matching의 채택은 확정하지 않는다.

```mermaid
flowchart LR
    A[문제와 사용 상황] --> B[정답과 관측 가능 범위]
    B --> C[상태와 확률 과정]
    C --> D[시간·공간 의존성]
    D --> E[출력 분포와 평가 기준]
    E --> F[후보 모형군 비교]
    F --> G[구체적인 아키텍처]
```

## 2. 모형 이름보다 먼저 답할 질문

| 큰 질문 | 검토할 선택지 | 선택에 필요한 근거 |
|---|---|---|
| 무엇을 예측해야 하는가? | 미래 API 재고, 특정 시점의 0대 확률, 여러 시점의 상태 경로, 거래량, 미충족 수요 | 사용 상황과 실제 정답의 존재 여부. API 재고를 거래량·잠재 수요로 바꾸지 않음 |
| 어떤 과정이 그 값을 만드는가? | 재고 유지·대여·반납·재배치·수리와 상태 조정, 서버 갱신·수집 누락 | 과정별 로그, 관측 간격, 시간대·갱신 시각, 식별 가능한 모수와 가정 |
| 무엇이 서로 의존하는가? | 같은 대여소의 과거, 도시 공통 시간 패턴, 인접·연결 대여소, 여러 미래 시점 | 자기 이력 대비 추가 정보, 거리·OD·기능·학습 관계의 의미와 안정성 |
| 어떤 불확실성을 표현해야 하는가? | 평균·분위수, 정수 재고의 주변 분포, 공간·시간 결합 분포 | 0대·꼬리·분산·지속성·대여소 간 동시 사건과 사용 목적 |
| 예측이 어떤 판단을 돕는가? | 이용자 안내, 운영 위험 요약, 수량·경로 결정 | 예측 지표와 별도의 비용·제약·운영 기록. 정책 효과에는 추가 검증이 필요 |

API 자료로 바로 평가할 수 있는 첫 범위는 **미래 API 관측 상태의 분포**다.
그 안에서도 한 시점의 주변 분포와 여러 대여소·여러 시점의 결합 분포 중 무엇이 필요한지는 아직 결정하지 않았다.
잠재 수요나 정책 효과를 연구하려면 추가 자료와 식별 가정을 별도로 정한다.

## 3. 관측과 실제 과정을 분리한다

개념적인 재고 과정은 다음처럼 나눌 수 있다.

`다음 재고 = 현재 재고 − 실제 대여 + 실제 반납 + 운영자 이동 + 수리·상태 조정`

그리고 API 응답은 그 상태가 서버에 갱신되고 수집되는 과정을 거친 관측이다.
API의 표시 재고, 실제로 고장 없이 이용할 수 있는 재고, 대여·반납 사건은 같은 변수가 아니다.

현재 API 스냅샷에서는 그 사이 일어난 대여·반납·운영자 이동을 각각 직접 관측하지 못한다.
일정한 과정 가정을 두고 유효 발생률을 추정하는 것은 연구할 수 있지만,
추정값을 실측 거래량이나 미충족 수요의 정답이라고 부를 수는 없다.
가정 아래의 식별 가능성과 실제 데이터에서의 타당성을 함께 검토한다.

현재 API로 미래 관측을 직접 예측하는 길과, 잠재 과정을 명시적으로 모델링하는 길을 둘 다 후보로 둔다.
[Gast 외, 2015](https://www.pure.ed.ac.uk/ws/files/23608488/Gast_et_al_2015_Probablistic_Forecasts.pdf)와
[Feng 외, 2017](https://doi.org/10.1016/j.peva.2017.09.004)은 과정 기반 가용성 예측의 출발 문헌이다.

## 4. GCN·포아송·Flow Matching이 맡을 수 있는 역할

| 도구·모형군 | 맡을 수 있는 역할 | 사용 이유를 확인할 질문 |
|---|---|---|
| 시간 모형·계수형 시계열·상태공간 모형 | 자기 이력, 유지·변화·주기와 상태 전이를 표현 | 짧은 시간의 재고 지속성과 변화가 어떤 구조인가? |
| GCN과 다른 그래프 모형 | 대여소 사이 정보를 전달하거나 분포·과정 모수의 공간 맥락을 구성 | 어떤 관계가 추가 예측 정보를 주며, 언제 관계가 바뀌는가? |
| 포아송·음이항·hurdle 등 계수형 분포 | 발생 횟수 또는 재고 관측의 조건부 분포를 표현 | 모형 변수의 의미·평균과 분산·0대 구조가 분포 가정과 맞는가? |
| Flow Matching과 다른 결합 분포 모형 | 여러 대여소·시점의 미래를 함께 생성 | 단순 주변 분포보다 결합 시나리오가 필요하고, 그 추가 가치가 측정되는가? |

### GCN: 관계를 어떻게 표현할 것인가

거리 그래프는 가까움을, OD는 이동 연결을, 상관·학습 그래프는 통계적 의존성을 표현한다.
같은 관계라고 가정하지 않는다. 그래프도 고정·학습·동적·방향성 등 선택지가 있다.
[Lin 외, 2018](https://arxiv.org/pdf/1712.04997)은 자전거 거래 자료에서 여러 그래프와 학습 필터를,
[Graph WaveNet, 2019](https://arxiv.org/pdf/1906.00121)은 교통 자료에서 학습 관계를 비교한다.

따라서 GCN을 넣기 전에 관계의 의미와 자료의 범위를 정한다.
자기 이력·공통 시간 정보 대비 추가 가치, 관계를 섞은 대조군, 시간 변화·새 대여소에 대한 안정성을 검토한다.
학습된 연결을 곧바로 인과 관계나 실제 이동 경로라고 해석하지 않는다.
GCN은 계수형 분포의 모수를 만들 수도, 과정 모형의 발생률이나 생성 모형의 맥락을 만들 수도 있다.

### 포아송: 무엇의 횟수 또는 발생률인가

서로 다른 두 사용법을 구분한다.

1. **사건 과정**: 대여·반납의 단위 시간당 발생률을 두고 재고 전이를 구성한다.
   재고 하한·경계, 운영자 이동, 실제 거래 자료와 관측 절단을 고려해야 한다.
2. **예측 분포**: 미래 API 재고 자체에 조건부 포아송 분포를 가정하는 기준 모형으로 쓴다.
   이때 모수는 미래 표시 대수의 조건부 평균이며, 대여 발생률이 아니다.

둘째 사용법도 시험 가능한 통계 모형이지만 자동으로 타당하지는 않다.
포아송은 조건부 평균과 분산이 같다. 흔히 쓰는 음이항 NB2는 분산이 평균 이상이다.
현재 재고가 주어졌을 때 변화가 작아 조건부 분산이 평균보다 작다면, 이들 가정이 제약이 될 수 있다.
반대로 과산포나 추가 0 구조가 확인되면 음이항·hurdle 등도 비교 후보가 된다.
대여소를 모두 섞은 원시 평균·분산이나 0 비율만으로 분포를 고르지 않는다.
후속 [H-0003](H-0003-results.md)은 개발 28일·현재 2~10대·적격 대여소에 한정해 이 조건을 진단했다.
30분 변동비의 대여소 중앙값은 0.449로 사전 0.8 미만 가설을 지지했다.
이는 당시 API 진단의 범위이며 포아송 사건 과정 전체의 기각이 아니다.
최신 계약에서는 이 통계로 후보를 좁히지 않고, 과거 대여·반납 자료의 정답과 분산 구조를 별도로 검토한다.
[DeepAR 확인본 §3.1](https://arxiv.org/pdf/1704.04110)은 시간 인코더와 계수형 likelihood를 나누어 보는 근거다.

### Flow Matching: 어떤 분포를 왜 함께 생성할 것인가

후보 목적은 미래 대여소 상태나 여러 시점의 경로를 조건부로 함께 생성하는 것이다.
독립 Gaussian·현재 상태에 조건부인 사전분포·시간 구조를 반영한 사전분포,
연속 dequantization·이산 상태 공간 등 설계 선택이 남아 있다.
[TSFlow, ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/ee1a1ecc92f35702b5c29dad3dc909ea-Paper-Conference.pdf)는
조건부 사전분포를 연구하며, [Discrete Flow Matching, NeurIPS 2024](https://arxiv.org/abs/2407.15595)는 이산 생성의 다른 경로를 제공한다.
후자의 언어 실험이 자전거 정수 재고에서의 유효성을 입증한 것은 아니다.

생성 과정의 내부 시간은 실제 자전거가 이동하는 시간이 아니다.
생성 궤적을 정책 변화의 인과 효과로 해석하려면 별도의 과정·개입 모형과 자료가 필요하다.
GCN·CFM·포아송을 모두 결합하는 경우에도 관측 모형과 잠재 변수의 의미를 먼저 정한다.
예를 들어 CFM으로 잠재 발생률을 만들고 포아송 관측을 붙이면 추가 혼합 분포 가정이 생긴다.
구성요소 수가 늘었다는 이유로 더 적합한 모형이라고 판단하지 않는다.

## 5. 비교할 큰 연구 방향 세 가지

아래는 후보군이며 추가·병합·철회할 수 있다. 어느 하나를 최종안으로 고르지 않았다.

| 방향 | 중심 질문 | 현재 자료에서의 가능성과 제약 | 더 구체화할 항목 |
|---|---|---|---|
| A. 관측 상태의 확률 예측 | API 재고의 조건부 분포·0대·회복을 어떻게 표현할까? | API 미래 관측으로 직접 검증 가능. 표시 상태와 실제 이용 성공은 구분 | 계수형 전이·분포 선택, 상태별 보정, 시간·공간 맥락 |
| B. 재고를 만드는 과정의 모델링 | 대여·반납·운영자 이동을 어떤 확률 과정으로 설명할까? | 스냅샷만으로 과정별 정답은 미관측. 추가 로그 또는 가정·식별성 검토 필요 | 사건률, 경계·관측 모형, 잠재 상태, 과정의 재현 가능성 |
| C. 공간·시간 결합 시나리오 | 함께 비거나 회복되는 여러 미래를 어떻게 생성할까? | 관측 격자의 결합 상태는 평가 가능. 격자 사이 사건과 정책 효과는 별도 | 자기회귀 계수형 모형·단순 결합 기준선·CFM, 사전분포, 정수 표현·의존성 |

GCN은 세 방향 모두에서 맥락 표현 후보가 된다.
포아송은 A의 예측 분포 또는 B의 사건 과정 후보가 될 수 있다.
Flow Matching은 C의 생성 방법 후보이며, 다른 방향과 결합할 때도 추가 가정을 명시한다.

## 6. 큰 방향에 맞춰 평가도 정한다

| 평가 대상 | 검토할 평가 | 주의할 해석 |
|---|---|---|
| 한 시점의 재고 분포 | 계수형 log score·CRPS, 구간·분위수 포함률, 재고 오차 | 평균 오차만으로 분포의 신뢰성을 판단하지 않음 |
| 0대·회복 확률 | Brier·확률 보정, 현재 0/양수와 희소 상태별 결과 | 계속 0인 상태와 전환 예측을 구분 |
| 여러 대여소·시점의 결합 분포 | 주변 분포 점수와 energy·variogram 등 결합 점수, 동시 저재고 사건 | 한 시점 Brier로 결합 의존성을 평가했다고 하지 않음 |
| 운영 판단 | 같은 제약·예산 아래 의사결정 손실과 비용, 필요하면 현장 비교 | 예측 개선을 실제 정책 효과로 대신하지 않음 |

결합 평가에는 [Scheuerer·Hamill, 2015](https://doi.org/10.1175/MWR-D-14-00269.1),
예측과 의사결정의 구분에는 [Gammelli 외, 2022](https://arxiv.org/abs/2108.00858)를 참고한다.
어떤 점수를 쓸지도 대상과 사용 목적에 따라 새 가설에서 동결한다.

## 7. 차근차근 좁혀 가는 작업 순서

| 단계 | 정리할 산출물 | 다음 단계로 넘어갈 조건 |
|---|---|---|
| ① 문헌의 문제·가정 비교 | 현재의 문헌 비교표, 원문 확인 범위, 옮겨 쓸 수 없는 가정 | 가까운 선행연구와 우리 자료의 차이가 설명됨 |
| ② 관측·모형 의미 계약 | API 상태·물리 상태·거래·운영 조치의 변수/단위/관측 여부 | 정답과 잠재 추정량이 섞이지 않음 |
| ③ 자료 구조 진단 | 별도 가설 PR에서 조건부 재고 변화·분산·0 구조·시간/공간 관계 조사 | 특정 모형군을 비교할 이유와 반증 조건을 정할 수 있음 |
| ④ 후보 모형군 비교 | 같은 출력·자료·평가·계산 예산의 작은 비교 | 필요한 분포 표현과 의존성에 대한 증거가 생김 |
| ⑤ 아키텍처 구체화 | 근거가 있는 인코더·관계·분포·과정/생성 구조와 대조 실험 | 각 구성요소의 역할과 추가 가치가 설명됨 |
| ⑥ 새 기간·사용 상황 검증 | 전향 평가와 필요한 운영 자료 검증 | 일반화·사용 판단에 대한 근거가 갖춰짐 |

①과 ②의 틀을 정리하고, ③의 첫 질문인 [H-0003](H-0003-results.md)을 사전 등록 뒤 dislab에서 완료했다.
이 API 진단은 과거 기록이다. 후속 자료 구조 진단은 과거 이력의 학습 구간에서 새 가설로 수행한다.
④의 모형군 비교는 아직 계획·평가 계약을 구체화하는 단계이며, 새 학습 예산과 최종 네트워크는 미정이다.
새 자료 탐색은 가능한 한 학습 구간부터 시작하고, 이미 본 시험 자료의 재사용을 기록한다.

## 8. 기존 H-0002가 차지하는 위치

[H-0002](H-0002-architecture-results.md)는 30분 뒤 관측 0대 확률에 대한 특정 소형 구현의 결과다.
API 학습 모델과 성능 순위는 최신 계약의 기준선·초기 가중치로 승계하지 않는다.
특히 다른 시간 범위·계수형 관측 모형·과정 식별·학습 그래프·조건부 사전분포·이산 생성·결합 분포의
필요성까지 결론 낸 것으로 취급하지 않는다.

이후의 새 질문과 선택 이유는 결정 기록에 남기고, 실험이 될 때마다 별도 가설 PR로 연결한다.

## 9. 과거 이력에서 새로 설계할 비교

다음 표는 이론적 선택지다. H-0003 통계에 따른 우선순위는 철회하며,
과거 이력의 정답·관측 범위·누락을 감사한 뒤 새 비교를 설계한다. 동결 계획이나 성능 순위는 아니다.

| 비교할 축 | 우선 검토할 대조 | 답하려는 질문·통제할 조건 |
|---|---|---|
| 관측 분포의 제약 | Poisson/NB2 참조 분포와 분산 유연한 정수 분포(CMP, 순서형 CDF 등) | 같은 과거·시간 정보로 분산 제약만 바꾸었을 때 0대·꼬리·분포 보정이 달라지는가? 큰 재고를 임의 상한으로 자르지 않는 표현 필요 |
| 현재 상태의 지속성 | 직접 미래 재고 분포와 현재 재고에 조건부인 계수형 전이 | 같은 출력에서 상태 유지·0대 진입·회복을 얼마나 표현하는가? 통계적 전이를 실측 거래 과정으로 해석하지 않음 |
| 예측 시간 범위 | 과거 이력의 시간 해상도와 사용 상황이 요구하는 범위 | 과거 내부 검증으로 비교하고 API 결과로 범위를 고르지 않도록 주 지표·보조 지표 동결 |
| 공간 정보 | 자기 이력·도시 공통 정보 대비 고정/학습 관계 정보 | 분포 표현을 통제한 뒤 GCN의 추가 가치·안정성 평가 |
| 결합 분포 | 주변 분포와 단순 결합 기준선 대비 조건부 생성 모형 | 여러 대여소·시점의 동시 사건을 판단할 필요가 있을 때 Flow Matching의 추가 가치·비용 평가 |

먼저 과거 이력에서 실현된 대여·반납 정답과 시간 누락을 확인하고 첫 학습 대상을 정한다.
API 재고와 거래 정답의 연결을 별도로 정의하며, 공간 모듈·생성기까지 동시에 바꾸지 않는다.
최소 비교군, 동일하게 줄 입력, 모형별 계산 예산, 꼬리 확률의 처리, proper score와 상태별 보정,
시간 경계·표본 선정·불확실성·성공 기준을 다음 가설에서 구체적으로 정한다.
분포를 잘못 지정한 모형의 점수 하나만으로 인코더나 전체 방법군의 가치를 판정하지 않는다.

기존에 본 API 날짜는 이미 열람한 외부 검증으로 명시하며 학습·선택에 다시 쓰지 않는다.
독립 검증은 모델·프로토콜 동결 이후의 새 API 수집 기간으로 남긴다.
