# 로컬 GPU에서 예측 모델 개발하기

현재 실행 위치는 이 채팅에 다시 제공된 AGENTS의 **dislab 지정**을 따른다. 아래 로컬 우선 전환은 H11/H12 당시의 이력이다.
H13에서 이를 늦게 대조해 이미 로컬에서 마친 학습은 실행 위치 위반으로 보존하며, 로컬 부분 평가는 중단했다.
고정 모델의 전체 재고 평가와 실제 새 예측은 dislab으로 옮겼다. 동결 계획과 원래 실행 환경을 소급 수정하지 않는다.

## 가설

2026-10-31 사용자 요청에 따라 후속 학습·추론·분석은 **이 컴퓨터의 GPU를 우선 사용**한다.
메모리와 작업 규모상 필요할 때 dislab을 보조로 사용한다. 이는 실행 장소의 변경이며 모델 성능 개선 가설이 아니다.
새 모델 비교는 기존과 같이 과거 기록으로 학습·선택하고 9월 API는 외부 평가 전용으로 유지한다.

## 실험

### 확인한 로컬 환경

| 항목 | 확인 결과 |
|---|---|
| GPU | NVIDIA GeForce RTX 4060 Laptop GPU |
| 장치 메모리 | 8,188 MiB |
| 학습 실행 환경 | Python 3.12, PyTorch 2.7.1+cu128, CUDA runtime 12.8 |
| 수치 라이브러리 | NumPy 1.26.4, SciPy 1.15.3 |
| 기본 작동 | 작은 CUDA 순전파·역전파, 라이브러리 의존성 검사 통과 |

프로젝트 전용 비공개 가상환경을 사용한다. 모델·원본·접속 설정을 공개 저장소에 넣지 않는다.
실행 전 여유 메모리를 확인하고 배치 크기·정밀도·시드·계산 예산을 해당 가설 계획에 기록한다.
이미 동결한 비교의 수치 조건을 바꿔야 한다면 새 가설로 분기한다.

### 모델과 학습 입력 준비

H-0010의 잠근 모델·계절 표·출력 10개 파일을 비공개 로컬 공간에 복사하고 selection 기록의 모든 해시를 확인했다.
기존 두 시드의 OD-GCN을 로컬 GPU에서 실행해 4개 시간 맥락×1,192개 대여소의 예측률 4,768개를 저장 출력과 비교했다.
최대 절대 차이는 **0.0000038147**로 사전 공학 허용 오차 `atol=rtol=0.00002` 안이었다.
수동 시작 상태 4개와 잘못된 입력 3개의 처리도 확인했다. 이 검사는 새 학습이나 API 정확도 평가가 아니다.
GCN의 예측률은 GPU에서 계산하고 재고 분포 요약에는 CPU 수치 계산을 함께 사용한다.

다음 학습에 필요한 다운로드 과거 이력 ZIP과 H4 달력·시간 집계, H7 OD 파일도 로컬에 준비했다.
ZIP 493,887,524바이트의 SHA-256은 기존 원본 목록의
`b43e78c373050d0aae2208db037538187066c565b7d5833f462b2ea94d42560b`와 일치한다.
나머지 파일도 각 공개 manifest의 해시와 대조했다. 학습 입력 준비 폴더에는 API 관측을 복사하지 않았다.
이는 출처·전송 무결성 확인이며 새로운 학습 성능이나 재고 검증 결과가 아니다.

### 기존 실험과 서비스의 구분

환경 전환 전에 시작한 H-0010의 본 학습·9월 평가는 동결 계획대로 dislab에서 완료했다.
그 [결과와 실행 기록](H-0010-seasonal-history.md)을 로컬 실험으로 소급 바꾸지 않는다.
여기에서 확인한 로컬 모델 이식과 기존 시연 서비스의 서버 이전은 별개다.
기존 시연 서버 전체의 이전이나 실시간 현장 배포를 완료했다고 주장하지 않는다.

## 결과

로컬 GPU 작동·고정 모델 이식·과거 학습 입력 준비를 완료했다.
[확인 요약](sources/local-gpu-readiness-v1.json)에 장치·버전·이식 오차·검사 범위를 기록한다.
후속 모델 실험의 기본 실행 장소는 로컬이다. 과거 여러 계절의 시간 분할과 긴 예측 공백을 다음 연구 질문으로 좁힌다.
분석·학습·선택에 API를 사용하지 않는 계약과 가설별 사전 Draft PR 원칙은 계속 적용한다.
