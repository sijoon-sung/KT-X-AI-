## 가설과 이번 범위

입력·층·출력·손실을 명시하면 encoder와 decoder를 각각 검토하고 구현과 설명의 불일치를 찾을 수 있다. 이번 작업은 기존 구현의 명세다. 새 모델의 성능 가설을 검증한 작업은 아니다.

현재 제품 기준은 H13이다. H22는 같은 입력을 쓰는 97MB 비교 모델로 남긴다. 이 역할은 H22의 과거 3월 사전 기준 실패 때 정했고, 9월 API로 다시 선택하지 않았다.
버스·철도·교통량·추가 기상·추가 도시·LLM을 예측 입력에 넣는 작업은 보류한다. 다음 신경망 변경은 이 입력 계약 안에서 encoder 또는 decoder 한 부분씩 새 가설 PR로 비교한다.

## 실험과 구현 명세

### 1. 고정 입력과 정답

`N`은 학습 대여소 수(1,318), `B`는 현재 배치에 포함된 대여소·시각 수다. API에 매칭되는 실제 개수는 달라진다.

| 입력 | 차원 | 역할 |
|---|---:|---|
| 과거 주간 프로필 | N×420 | 과거 대여·반납 패턴. 7일×30개 반시간 슬롯×2종 건수를 정규화한 정적 표현 |
| 과거 OD 관계 연산자 A | N×N | 같은 학습 자료에서 고정한 대여소 관계 |
| 자기 과거 평균 특징 | B×6 | 기본·주간·계절 대여/반납 평균의 로그 표현 |
| 달력 | B×35 | 요일 7, 시각 24, 반시간 구간 2, 월 주기 2 |
| 10분 위치 | B×3 | 반시간 안의 세 10분 구간 |
| 기상·결측 표현 | B×54 | 기존 인코딩을 유지. 운영 래퍼는 원래 결측 인코딩을 사용 |
| 최근 자기·이웃 순흐름과 유효성 | B×4 | 자기 2 + 이웃 2. 학습은 직전 완료 거래, 추론은 직전 API 재고 차이의 대리 입력 |
| 현재 API 재고 | B | 마지막 재고 계산의 시작 상태. 신경망 학습 정답이 아님 |

학습 정답 `y=(대여 건수, 반납 건수)`는 다음 10분의 완료 거래다. 실측 재고·잠재 수요와 구분한다. API는 학습·튜닝·정규화·분포 선택·보정에 쓰지 않는다.

### 2. Encoder: 정적 주간 표현과 현재 조건 결합

| 단계 | H13 | H22 | 구현 |
|---|---|---|---|
| 주간 프로필 | Linear420→256, SiLU, Linear256→64, LayerNorm64 | 동일 | `forecast_transfer.WeeklyEncoder` |
| 관계 집계 | z=encoder(profile), n=A@z | 동일 | `Forecaster.encode` |
| 자기 입력 | 6+35+3+54+64+2 = 164 | 동일 | `Forecaster.rate` / `MemoryForecaster.rate` |
| 이웃 입력 | 6+64+2 = 72 | 동일 | 동일 |
| 자기·이웃 투영 | Linear164→256 + Linear72→256(bias 없음), SiLU | 각각1280차원 | `Forecaster` / `LargeForecaster` |
| 현재 조건 표현 | Linear256→256 + SiLU, 2회 | Linear1280→1280 + SiLU, 4회 | `layers` |
| encoder의 최종 조건 h | B×256 | B×1280 | 평균 decoder와 FM 양쪽에 전달 |

현재 encoder는 정적 주간 프로필 MLP와 한 번의 OD 집계, 현재 조건 MLP로 구성된다. 입력 시퀀스를 순회하는 Transformer·GRU나 여러 시점의 그래프 전파를 구현한 것으로 설명하지 않는다. 원 코드에서 `encoder` 속성은 주간 MLP만 가리키며, 위 표는 예측 경로 전체의 기능 경계다.

### 3. Decoder A: 대여·반납 평균과 포아송 경로

`a=Linear(h)`는 B×2다. 평균은 `lambda=prior*exp(2*tanh(a/2))`로 양수가 된다. 순서는 대여, 반납이다.

- H13: Linear256→2. H22: Linear1280→2.
- 학습 손실: `mean(lambda-y*log(lambda))`. 모수와 무관한 `log(y!)`는 제외한다.
- 포아송 비교 경로: 같은 평균에서 두 종류의 건수를 독립 표집한다.

### 4. Decoder B: 조건부 Flow Matching

| 항목 | H13 | H22 |
|---|---|---|
| 조건 표현 | h 256차원 | h1280을 Linear1280→1280 3회, Linear1280→128, 각 SiLU로 변환 |
| 조건 계산 | h를 바로 사용 | 대여소별 한 번 계산해 캐시 |
| 속도장 입력 | 잔차2 + 시간표현4 + h256 + 중심2 = 264 | 잔차2 + 시간표현4 + 캐시128 + 중심2 = 136 |
| 속도장 네트워크 | 264→128→128→128→2, 은닉 SiLU | 136→128→128→128→2, 은닉 SiLU |
| 생성 | 2차원 Gaussian 잡음, Heun16, 128개 IID 혼합 표본 | 동일 |

중심은 `log1p(lambda)`다. 학습에서는 정답 건수에 `u~Uniform(0,1)^2`를 더해 `r1=log1p(y+u)-log1p(lambda)`를 만든다. 독립 `r0~Normal(0,I2)`, `s~Uniform(0,1)`에 대해 `rs=(1-s)*r0+s*r1`와 목표 속도 `r1-r0` 사이의 MSE를 줄인다.

추론 시 적분한 잔차에서 `max(0,floor(expm1(r+log1p(lambda))))`로 건수를 얻는다. 출력은 B×128×2다. 비유한 값·정수 범위 초과는 실패로 처리한다. 시드11·29 모델을 표본마다 독립 선택하며 평균 예측 두 개를 단순 평균한 표본이 아니다.

포아송 표본을 FM으로 다시 운반하는 구조는 아니다. FM은 같은 평균과 h를 조건으로 독립 Gaussian에서 생성한다. Heun의 경로는 건수 잔차 공간의 적분 경로이며 재배치 차량 동선과 다르다. 최적수송 결합·도시 전체 공동분포·RL은 구현하지 않았다.

### 5. 재고 출력과 재배치 경계

`b_next=max(0,b_now+생성 반납-생성 대여)`로 B×128개의 재고 표본을 만든다. 중앙값·범위·0대 확률을 계산하고, 고정 표본을 H21 계산기에 전달해 공급·부족 수량과 방문 순서를 구한다. 재배치 계산기는 신경망 decoder와 별도다.

현재 재고 계산은 상한 주차 용량이나 사건 발생 순서를 복원하지 않는다. 0대일 때 포기한 이용자의 잠재 수요도 직접 관측하지 못한다. 배차 효과는 실제 행동·결과 자료로 별도 검증해야 한다.

### 6. 학습 순서

1. 과거 서울의 미래 대여·반납 예측으로 학습한 주간 encoder를 초기값으로 사용한다.
2. 타슈 과거 완료 거래에서 주간 encoder·조건 결합·평균 head를 함께 학습하고 2월 이력으로 선택한다.
3. 이 예측망을 고정하고 FM만 학습·선택한다. 현재 구현은 encoder와 FM의 종단간 공동 학습이 아니다.
4. 가중치·입력·시드·표집을 잠근 뒤 API 재고를 평가한다.

`forecast_transfer.Autoencoder`의 64→256→420 복원 decoder는 이전 사전학습 비교용이다. 현재 미래 건수·재고를 출력하는 decoder로 사용하지 않는다.

소스와 기존 가중치 감사 기록을 기준으로 차원·층·손실·자료 경계를 정리했다. 신경망 코드·가중치·API 평가 규칙을 바꾸거나 새 정확도를 측정하지 않았다.

| 두 시드 GCN+FM 파라미터 | 768,648 | 24,245,640 |
| 체크포인트 전체 파일 | 5.64MB(기준선 포함) | 97.00MB |
