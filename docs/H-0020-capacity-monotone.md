# H-0020 · 더 큰 차량에서도 좋은 경로 보존

## 가설

H19의 제한된 빔 탐색은 적재량을 늘리면 탐색 가지도 달라져 작은 차량에서 찾은 좋은 경로를 놓칠 수 있다. 다른 조건이 같을 때 적재량1부터 요청값까지의 실행 가능한 해를 함께 보존하면 이 역전을 막을 수 있다. 이는 경로 집합의 포함 관계에 따른 구현 개선이며 새 예측 모형을 고르는 실험이 아니다.

## 실험

H19의 후보·손실·비용·공급지 보호·도로·10분 유효시간은 유지한다. 가중치와 API 자료 계약도 유지한다. 사전 Draft PR과 코드 게시 뒤 dislab CPU에서20개 합성 사례×6개 적재량을 검사한다. 새 API 한 회차는 기능 예시로만 기록하고 모델 정확도·실제 결품 예방의 정답으로 사용하지 않는다. H19의 원래3회차 비교는 원래 고정 코드로 끝낸다.

## 결과

판정 `supported`. dislab CPU에서20개 합성 사례×적재량1~6의120조건 모두 수량·중간 적재·복귀 제약과 적재량 포함 관계를 지켰다. 위반0건. 합성 풀이 중앙값0.0051초·최대0.0118초다. 이 작은 합성 사례에서 기존 H19의 역전도0건이었으므로, 합성 사례가 실제로 발견한 오류 수라고 확대하지 않는다. 포함 관계는 모든 작은 적재량의 실행 가능한 해를 후보 집합에 넣는 구성으로 보존한다.

새16:00관측에서는16:00:12에16:10까지의 계획을 발행했다. 기존 단일 적재량 탐색2대/0대1곳 공급 대신, 적재량별 해를 함께 보존한 계획은4대/0대3곳 공급·7.1332km·9.1817분 복귀였다. 풀이0.116초·도로 조회 등을 포함한 발행 계산2.595초다. 거리 자체가 짧아진 것은 아니며 동일한 가정 비용 안에서 공급 효과의 모델 대리값을 비교한 결과다.

방문 순서: 태평동 버드내초등학교2대 수거 → 태평동 삼부프라자1대 수거 → 가장동 큰손부추해물칼국수1대 배치 → 유천동 새서울종합시장1대 수거 → 문화동 세이백화점1대 배치 → 문화동 BMK컨벤션2대 배치 → 출발지 복귀. 중간 적재 최고3대·마지막0대다. 현재0대544곳 중541곳은 이번 계획 밖에 남는다.

차량1대/적재6대·출발지·상하차6초/대·추가 주차 최대3대는 가정이다. 실제 차량 위치·주차 가능량·교통·행동 로그를 확인한 배차가 아니다. 재배치가 미래 이용을 바꾸는 효과도 관측하지 않았다. 이 해는 후보26곳과 최대6회 방문의 제한 탐색이며 도시 전체 최적이 아니다.

수집기와 별도로 새 관측마다 자동 계획을 저장하며, 화면의 조건 변경은 dislab에서 새로 계산한다. 가중치와 고정 예측은 유지했다. 다음 단계는 확인된 차량·작업·주차 조건과30/60분의 별도 동결 예측 평가를 갖추는 것이다.

원격 운영체제 시계가139.524초 느리다. 원본 실행 시각과 H18 보정값으로 환산한 UTC 추정을 모두 공개 JSON에 남겼다(불확실성0.616초). 실제 계획 발행과 만료 판단은 H18의 보정된 단조 시계를 사용한다. 소급 발행이 아니다.

근거: `research/runs/H-0020-20261101-capacity-union/manifest.json`. 동일한 고정 상태·후보·도로 행렬·비용·시간에서 적재량만 늘리는 경우에 한정해 작은 차량의 실행 가능한 경로를 보존한다.
