# H-0020 · 더 큰 차량에서도 좋은 경로 보존

## 가설

H19의 제한된 빔 탐색은 적재량을 늘리면 탐색 가지도 달라져 작은 차량에서 찾은 좋은 경로를 놓칠 수 있다. 다른 조건이 같을 때 적재량1부터 요청값까지의 실행 가능한 해를 함께 보존하면 이 역전을 막을 수 있다. 이는 경로 집합의 포함 관계에 따른 구현 개선이며 새 예측 모형을 고르는 실험이 아니다.

## 실험

H19의 후보·손실·비용·공급지 보호·도로·10분 유효시간은 유지한다. 가중치와 API 자료 계약도 유지한다. 사전 Draft PR과 코드 게시 뒤 dislab CPU에서20개 합성 사례×6개 적재량을 검사한다. 새 API 한 회차는 기능 예시로만 기록하고 모델 정확도·실제 결품 예방의 정답으로 사용하지 않는다. H19의 원래3회차 비교는 원래 고정 코드로 끝낸다.

## 결과

미실행. 작은 적재량에서 가능한 경로를 보존하는지, 수량·중간 적재·복귀·예측 유효시간 제약을 지키는지 검증한 뒤 기록한다. 도시 전체 최적과 운영 효과는 아직 확인하지 않았다.
