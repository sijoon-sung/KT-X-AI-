# H-0006 결과: 수량 점수 악화와 점출력·손실의 불일치

[PR #11](https://github.com/sijoon-sung/KT-X-AI-/pull/11)·[동결 계획](H-0006-loss-consistent-action.md)·[실행 manifest](../research/runs/H-0006-20261031-loss-action/manifest.json).
공식 평가는9월 API다. 같은 분포의 다른 요약을 비교했으며 API로 재학습·보정·분포/모형/손실/분위수를 선택하지 않았다.

## 1. 가설

동일하게 고정한 과거 흐름→재고 분포에서 MAE에 대응하는 하위중앙값을 내면 평균 출력의 MAE를0.01대 넘게 줄일 것이다.
[Gneiting2011 저자 원문 §1.3·Table5](https://arxiv.org/pdf/0912.0902)의 제곱손실↔평균·절대손실↔중앙값 구분을 적용했다.
모형 자체 분포에서의 이론적 최적성과 실제 자료의 성능은 구분한다.
주 점추정·3일/7일 두95%구간 하한모두>0.01대와 자료충분성을 사전에 요구했다.

이 질문은 H-0005의 수량 MAE 악화를 본 뒤 추가했다. 기존 보고·판정·수치를 소급 수정하지 않는다.
이번에 확인할 것은 손실/결정의 영향이며, 전체 아키텍처의 좋고 나쁨이나 과정 오류의 개별 원인을 단정하지 않는다.

## 2. 실험

과거 전용 H4 달력률 가중치와 H5의0반사·용량상한없는 사건 과정·30분 시간을 그대로 고정했다.
현재 API는 초기 상태이고 미래 API는 정답이다. 학습·튜닝·사건률 보정은 없다.
현재 유지, 같은분포 평균, 같은분포 하위중앙값(min{k:CDF(k)>=0.5})을 비교했다.
평균은 제곱손실/RMSE, 중앙값은 MAE, 같은0대 확률은 Brier, 분포는 CRPS와 고정5~95%분위수로 각각 보고한다.

H5와 같은9/17~30·정시07~21시·현재/목표 모두9월·정확한ID·시각·누락 계약을 적용했다.
정확한 대응ID 1,176개, 전체 유효 237,222쌍, 14일이다. 누락330칸은0으로 채우지 않았다.
포아송 균일화K=106는 과거 계수만으로 API열기전에 정했다.
전방 분포의 수치 지지집합은 현재재고±K이며 음수확률0·0반사이고 큰재고 상한 절단은 없다.
H5와 같은 정규화된 반복횟수 절단 분포이므로 분포를 교체한 실험이 아니다.

합성검사9개(해석해·행렬지수·기존후방방법 일치·중앙값 손실·CRPS·큰상태 등), 기존H5 경계검사10개, 사전 기록검사14개를 통과했다.
첫 합성검사에서 전방재귀의0경계 구현을 수정하고 실제 API실행 전에 재검사·코드게시했다.
계획 게시 `cf64c0b126b97a2a83b46328a9a676b518220e691085ca8314ff6693ef42976d`(계획SHA), 커밋 `f54ca1a4ef5c6ebe3cece442fdf71d35d1bf2a8f`.
실행 전 구현 게시 `a85d3f691d83a63551ddad5093739bc60e2ecd23`.
dislab CPU4스레드, Python3.12.10·NumPy1.26.4·SciPy1.15.3, 약57.20초.
14개 원본 달력날짜를 유지한 도시동기화3일/7일 이동블록 각2,000회, PCG64seed20261031, 유효복제각2,000회다.

### 원인 해석과 개선 방향

- 확인한 원인: 평균과MAE를 단일 수량 성능으로 읽은 불일치. 같은 분포의 중앙값 비교가 이 부분을 분리했다.
- 남는 한계: 기준선 대비 중앙값 MAE 개선의 불확실성, 대부분 현재 재고를 내는 짧은시간의 점출력, 상태별 분포 불일치.
- 아직 분리 못한 원인: 과거→9월 변화, 완료거래의 가용성 절단, 독립/무기억 가정, 재배치·관측 지연. 현재 자료만으로 각 원인의 몫을 계산하지 않는다.
- API의 관측 bias나 포함률로 사건률·분위수·확률을 보정하지 않는다. GCN·FM의 채택 여부도 이 점수로 정하지 않는다.

기존 H5와 원래 결과는 보존한다. H6 구현은 재현 가능한 평가 도구로 보존하고 기본 운영 모델 채택은 하지 않는다(`adopt_code=false`).
9월은 H5와 과거 작업에 이미 노출된 반복 공식 평가다. 독립 미열람 시험이 아니며 계수추정/반복선택 불확실성은 구간에 포함하지 않는다.
