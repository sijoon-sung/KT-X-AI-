# 학습 범위를 넓히는 예측 연구

## 가설

2026-10-31 사용자 요청에 따라 연구 범위를 9월의 달력 패턴에 한정하지 않는다.
**외부 평가 기간과 학습 가능한 정보의 범위는 다르다.** 공식 9월 재고 평가는 보존하면서
여러 계절의 과거 거래로 표현·입력·용량을 연구한다. 학습·선택에 타슈 재고 API를 사용하지 않는다.

정보 확대와 용량 확대를 분리한다. 서울 번호를 대전 번호에 대응시키는 대신,
두 도시에서 같은 방식으로 만든 대여·반납의 요일/시간/계절 프로필을 공유 인코더에 넣는다.
출퇴근형·주말형 등은 기대하는 해석이지 확보된 정답 라벨이 아니다.
[RegionTrans](https://ijcai.org/proceedings/2019/262)는 도시 간 표현 이전의 출발 근거다.
학회 초록과 [저자 원문](https://arxiv.org/pdf/1802.00386)의 지역 매칭·전이 구조를 확인했다.
우리의 프로필 인코더는 해당 방법 전체의 재현이나 성능 승계를 뜻하지 않는다.

## 실험

| 순서 | 질문 | 비교 범위 |
|---|---|---|
| H-0011 | 표현·기상·용량 확장이 다른 계절의 거래 예측에 도움이 되는가? | 작은/큰 달력 GCN, 큰 기상 GCN, 무작위/서울 사전학습 인코더. 과거 기록 건수만 내부 비교 |
| 후속 재고 연결 | 새 거래 모형이 상태 전이 예측을 개선하는가? | 과거에서 선택을 마친 가중치·전처리·분포·평가 계획을 동결한 뒤 공식 9월 외부 평가. 추가 기간은 별도 계획 |
| 후속 확률 모형 | 평균만 잘 맞추면 충분한가? | 포아송·음이항 등과 새 맥락에 조건화한 Flow Matching. 과거에서 분포 비교 후 외부 평가 |
| 후속 시계열·운영 | 최근 입력과 공동 시나리오가 필요한가? | 실제 확보한 최근 거래/운영 자료만 입력. 도시 공동 시나리오·재배치 효용은 별도 검증 |

### 실제 확보한 원본

- [서울 열린데이터광장 OA-15182](https://data.seoul.go.kr/dataList/OA-15182/F/1/datasetView.do)의
  2024년 원천 대여이력 ZIP: **2,068,679,477바이트**, 월별 CSV 12개.
  대여/반납 시각·양쪽 대여소 번호를 헤더에서 확인했다. 공공누리 제1유형 출처표시를 따른다.
  기존 H9의 2017~2018 UCI 도시 합계 네 특성과 다른 자료다.
- [NOAA GHCNh](https://www.ncei.noaa.gov/products/global-historical-climatology-network-hourly)의
  대전 KSI0000RKTF, 2024·2025·2026년 파일을 실제 확보했다. 2026년 파일은 10월28일13시 UTC까지다.
  서울 KSI0000RKSL의 2024년 자료도 확보했다. H11의 첫 이전은 서울 거래 프로필이며
  서울 날씨 사전학습까지 수행했다고 보고하지 않는다.
- 구 ISD 대전 2025년 파일은 8월에 끊기고 2026년은 404여서 후속 제품 GHCNh로 전환했다.
  빈 기간을 정상 날씨나 0으로 채우지 않는다.

원본은 비공개 보관하며 공개 명세에는 식별자·해시·출처만 기록한다.
전체 행 검사·집계·학습은 가설 계획을 게시한 뒤 수행한다.

### 입력과 모델 확대

1. 양 도시의 대여소를 456차원 프로필(주간420·월별24·월 관측 마스크12)로 표현한다.
   서울에서 64차원 인코더를 학습하고 타슈의 각 학습 분할까지만 만든 프로필에 적용한다.
2. 타슈 과거 전용 OD 이웃을 GCN으로 반영한다. 양 도시의 그래프·ID를 섞지 않는다.
3. 기온·풍속·습도·3시간 강수 보고를 넣는다. 예측 시작 1시간 이전 보고와 최대 나이·결측 마스크를 사용한다.
4. 같은 학습 예산에서 폭32/1층과 폭256/3층을 비교한다. 무작위 인코더 대조로 차원 증가와 사전학습 효과를 구분한다.

GHCNh는 사후 수정된 관측 아카이브다. 시각 제한은 과거 맥락 실험이며 실시간 도착 보장의 운영 검증이 아니다.
한 관측소의 도시 대표성도 한계다. 외생 기상 자료는 타슈 재고 API와 별도의 입력이다.

## 결과

작성 시점에는 원본 확보·헤더 확인을 완료했고 새 정확도 결과는 아직 없다.
수집을 학습 완료나 성능 검증으로 부르지 않는다. 다음 행동은 H-0011 계획을 Draft PR에 동결하고
로컬 GPU에서 전처리·사전학습·대조 실험을 실행하는 것이다. 실패·효과 없음도 보존한다.
거래 지표를 재고 정확도로 바꾸어 보고하지 않는다. 기존 H9/H10의 제한된 결과를
전체 GCN·전이학습·Flow Matching의 결론으로 확대하지 않는다.
