# H-0009: 규모 확대·따릉이 특성·Flow Matching 융합

## 가설

큰 GCN으로 계절·반시간 맥락을 표현하고 서울 과거 패턴을 공통 특성으로 넣으며, 조건부 Flow Matching으로 30분 대여·반납 공동 건수를 생성하면 재고 예측을 개선할 수 있는가?
small → large → large+Seoul → large+Seoul+CFM을 통제하여 비교한다. 기존 H7/H4도 고정 참고로 둔다.

## 실험

과거 다운로드 거래로만 학습·2월 선택한다. 실제 30분 대여/반납 건수를 만들며 실측 재고로 부르지 않는다.
따릉이는 [UCI 공식 자료](https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand)의 2017~18년 도시 집계다.
비운영 시간을 빼고 월·시간·요일×시간·월×시간 패턴 네 개를 고정한다. 서울 대여소 재고나 2026년 동시 상황·대전 날씨 특성이 아니다.
작은 GCN은 1층32폭, 큰 GCN은 3층128폭, 각2시드·20epoch다. CFM은 선택한 큰 GCN 조건에서 실제 거래 쌍을 생성하는 별도 head이며 2차원 분포에 한정한다.
CFM 생성시간과 실제 30분을 구분하고 반사 경계의 사건 순서를 반영해 재고로 연결한다.
전체 계획·정수화·ODE·표본/검증/불확실성 규칙은 [동결 JSON](../research/hypotheses/H-0009.json)에 있다.
공식 재고 평가는 9월 API에 고정한다. 미래 정답은 별도이며 학습·튜닝·API 승자 선택은 없다.
현재 0/양수·수량·확률을 함께 보고 전체 CRPS의 최소 대조군 개선 1%를 주 가설로 둔다.
연산은 dislab에서 수행한다. 실시간 시제품과 새 연구 후보를 구분하여 연결한다.

## 결과

미실행. 계획 게시 후 합성검사·구현 게시·학습·가중치 동결·3월 보조 진단·9월 공식 평가 순서로 진행한다.
성능 우위를 미리 보장하지 않는다. 실패와 불확실성도 보존하며 기존 시제품을 유지한다.
