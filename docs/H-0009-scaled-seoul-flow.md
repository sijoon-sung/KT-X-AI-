# H-0009: 규모 확대·따릉이 특성·Flow Matching 융합

## 가설

큰 GCN으로 계절·반시간 맥락을 표현하고 서울 과거 패턴을 공통 특성으로 넣으며, 조건부 Flow Matching으로 30분 대여·반납 공동 건수를 생성하면 재고 예측을 개선할 수 있는가?
small → large → large+Seoul → large+Seoul+CFM을 통제하여 비교한다. 기존 H7/H4도 고정 참고로 둔다.

## 실험

과거 다운로드 거래로만 학습·2월 선택한다. 실제 30분 대여/반납 건수를 만들며 실측 재고로 부르지 않는다.
따릉이는 [UCI 공식 자료](https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand)의 2017~18년 도시 집계다.
비운영 시간을 빼고 월·시간·요일×시간·월×시간 패턴 네 개를 고정한다. 서울 대여소 재고나 2026년 동시 상황·대전 날씨 특성이 아니다.
작은 GCN은 1층32폭, 큰 GCN은 3층128폭, 각2시드·20epoch다. CFM은 선택한 큰 GCN 조건에서 실제 거래 쌍을 생성하는 별도 head이며 2차원 분포에 한정한다.
CFM 생성시간과 실제 30분을 구분하고 반사 경계의 사건 순서를 반영해 재고로 연결한다.
전체 계획·정수화·ODE·표본/검증/불확실성 규칙은 [동결 JSON](../research/hypotheses/H-0009.json)에 있다.
공식 재고 평가는 9월 API에 고정한다. 미래 정답은 별도이며 학습·튜닝·API 승자 선택은 없다.
현재 0/양수·수량·확률을 함께 보고 전체 CRPS의 최소 대조군 개선 1%를 주 가설로 둔다.
연산은 dislab에서 수행한다. 실시간 시제품과 새 연구 후보를 구분하여 연결한다.

## 결과

모델 구현의 채택과 공식 재고 성능 판정은 구분한다. API 점수로 서비스의 승자나 가중치를 고르지 않았다.

공식 공통 표본은 대여소 1,176개·유효 관측쌍 237,222개다.
현재 양수·현재 0·전체를 [실제 집계](../research/runs/H-0009-20261031-scaled-seoul-flow/summary.json)에 구분했다.
현재 유지의 전체 CRPS/MAE는 0.579567대다.
주 지표인 다섯 대조군 대비 **최소 상대 CRPS 감소는 -0.371%**다.
3일 블록95%구간은 -0.770%~-0.262%,
7일 블록은 -0.585%~-0.371%다. 사전 기준은 점 추정과 두 하한이 모두 1%를 넘는 것이다.
음수 감소율은 악화를 뜻한다. 한 보조 지표의 개선으로 주 판정을 바꾸지 않는다.

GCN은 1층32폭에서 3층128폭으로 확대했다. 큰 인코더 75,394개와 CFM 50,818개, 합계126,212개가 시드당 학습된다.
기존 H7의 시드당1,762개와 구분하며 새 작은 대조군은 같은34입력의2,274개다.
서울 특성 유무의 큰 모델은 같은 모수 수다. 학습은 각2시드이며 앙상블 가중치도 사전 동일 고정이다.

모든 저장 epoch는 **2월 과거 거래 자료**에서 정했다. CFM은 같은 조건의 고정 벡터장 회귀 손실로 선택했다.
학습·원본 재처리·선택·3월 보조 진단은 494.9초,
9월 평가 연산은 474.1초였다. dislab의 GPU 학습과 CPU 평가를 사용했다.
GPU 최대 사용량의 실제 바이트 수와 환경은 [학습 기록](../research/runs/H-0009-20261031-scaled-seoul-flow/training.json)에 있다.

3월의 보조 거래 deviance는 작은 모델 1.088146,
큰 모델 1.162637,
큰 모델+따릉이 0.946413였다.
이 수치는 **거래 건수**이며 3월 실측 재고를 얻은 결과가 아니다. 모델 선택·API 보정에 사용하지 않았다.

실행 계획 `6121970b77643445e7931052d4c80d31a419aa0f`와
학습/평가 구현 `4ff082f7d85daa78f692e426185eee05c4299fb4`를 실행 전에 게시했다.
모델·전처리·생성 표본을 해시로 고정한 뒤 9월 API를 읽었으며 모든 파일은 [실행 manifest](../research/runs/H-0009-20261031-scaled-seoul-flow/manifest.json)에 연결한다.
원본·개별 거래·실측 재고/예측 배열·가중치·접속 정보는 공개하지 않았다.

H9 합성 검사10개, 새 서비스4개, 기존 서비스8개와 프로토콜14개를 dislab에서 통과했다.
반사 경계는 작은 사건 순서를 전부 열거한 경우와 비교했고, CFM 손실이 실제 최적화되는지도 검사했다.
서비스에서는 새 연구 모델과 기존 GCN을 같은 현재 상태에서 비교한다. 미래 관측은 별도 조회다.

따릉이는 [UCI 공식 자료](https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand),
DOI10.24432/C5F62R·CC BY4.0의2017~18년 도시 집계다. 서울 대여소 재고·실시간 상황·대전 날씨를 대신하지 않는다.
GCN 조건부 [Flow Matching 원문 §3](https://arxiv.org/html/2210.02747v2)의 벡터장 회귀를 사용했고,
도시 전체의 결합 분포나 최적 수송을 재현했다고 주장하지 않는다.
512개 생성 표본,16단계 Heun,정수화·0반사·균등 사건 순서가 근사다. 구간에는 학습/선택/Monte Carlo 불확실성이 모두 반영되지 않았다.
거래율은 완료된 흐름이며 공급 노출·운영자 이동·용량과 잠재 수요는 미관측이다.
공식9월은 이미 여러 번 열람한 기간이다. 2·3월의 재고 정답이나 현장 운영 효용을 얻은 것은 아니다.

다음 개발은 저장한 모델을 유지하며 입력 가능한 정보의 범위와 과거 기간 간 일반화를 점검하는 것이다.
새 개선 실험은 과거 자료의 시간 분할에서 계획·선택한 뒤 별도 가설 PR로 남긴다. 9월 API에 맞춰 이 가중치를 재튜닝하지 않는다.
