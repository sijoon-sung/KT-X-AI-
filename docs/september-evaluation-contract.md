# 공식 평가는 9월 API 재고로 고정한다

기준일: 2026-10-31. 사용자가 지정한 **9월 API 평가**가 기존의 기간 해석보다 우선한다.
이 문서는 평가 대상·자료 역할의 정정이며 새로운 성능 실험 결과가 아니다.

## 1. 가설

프로젝트가 검증하려는 것은 **과거 이력으로 학습한 모형이 9월의 미래 API 재고·0대 여부를 예측할 수 있는가**다.
구체적인 모형·예측 시간·주 지표·판정 기준은 해당 실험의 새 가설 PR에서 동결한다.
2·3월 거래 건수의 예측 개선을 이 가설의 입증으로 대체하지 않는다.

| 자료 | 직접 확인할 수 있는 정답 | 연구 역할 |
|---|---|---|
| 다운로드 과거 이력, 2024-08~2026-03 | 기록된 대여·반납 거래와 시각. **그 당시 실측 재고·품절 정답은 없음** | 학습과 보조 거래 건수 진단 |
| 2026년 2·3월의 다운로드 이력 | 기록 거래 건수. **2·3월 재고·품절 정답은 없음** | H-0004의 보조 내부 비교. 프로젝트 공식 재고 평가는 아님 |
| 2026년 9월 API 수집본 | 유효 관측 시점의 표시 재고 `parking_count`, 관측 0대 여부 | **고정된 공식 재고 평가 자료** |
| 거래로 복원한 과거 재고 | 가정 아래의 추정량·하한이며 실측 정답이 아님 | 가정을 명시한 모델링 후보. 공식 정답으로 대체 금지 |

## 2. 실험

### 공식 평가 기간과 입력 경계

- 평가 기간은 **2026-09-01 00:00 이상~2026-10-01 00:00 미만**, 한국 시간 조건부 해석이다.
- 기존 [API 입력 목록](../research/datasets/tashu-primary-v1.json)의 9월 수집분을 사용한다.
  현재 확인한 백업의 9월 원본은 9월 17~30일이다. 자료가 없는 9월 초를 가상으로 채우거나 한 달 전체 관측으로 부르지 않는다.
- 기존 44일 원본 목록과 과거 가설의 동결 해시는 수정하지 않는다. 새 평가 manifest에는 9월 원본·해시·시간 필터를 명시하고,
  시작 관측과 미래 정답 모두 9월 안에 있도록 검사한다. 10월 정답으로 경계를 넘지 않는다.
- 10월이나 새 API 기간으로 공식 평가를 바꾸거나 넓히지 않는다. 별도 추가 검증은 사전에 분리해 정의한다.
- 과거 이력의 대여·반납 모델은 흐름을 학습하는 구성요소일 수 있다.
  재고 평가에는 이 흐름이 미래 상태로 연결되는 과정·경계·운영 이동·초기 상태 가정을 별도로 정해야 한다.
- 평가 시작 시점에 알려진 정보와 미래 정답을 구분한다. API 현재 상태가 검증 입력으로 필요한 경우
  시작 시점·허용 시차·사용 범위를 새 평가 계획에 고정하고, 미래 API 값을 입력·초기 상태에 넣지 않는다.
- API 관측으로 학습·미세조정·조기 종료·모형/분포/하이퍼파라미터/임계값 선택·확률 보정을 하지 않는다.
- 누락은 0대 정답이 아니다. 대여소 ID 대응, 현재/목표 관측 유효성, 실제 경과 시차, 평가 가능 표본 수를 보고한다.
- 재고 오차와 0대 확률은 평가 대상이 다르다. 지표와 현재 0/양수 상태별 보고 규칙은 새 가설에서 고정한다.

### 기존 실험 기록을 다루는 방법

H-0004는 과거 기록 거래 건수의 별도 가설이었다. 그 동결 계획·분할·수치·판정은 그대로 보존한다.
다만 프로젝트 안에서의 위치는 **흐름 추정기를 학습하기 위한 보조 진단**이다.
2월 평활 강도 선택과 3월 건수 deviance 비교는 재고·품절 모형의 검증이나 채택 근거가 아니다.
H-0004의 두 학습 모델은 재고 평가에 연결할 때 새 계획에서 역할을 정해야 한다.

H-0002의 API 학습과 H-0003의 API 탐색도 과거 기록으로 남긴다.
9월 자료는 이미 이런 작업에 노출됐으므로 미열람 독립 시험이라고 설명하지 않는다.
**노출 사실을 기록하면서도 사용자가 지정한 공식 9월 평가 자료는 유지한다.**
새 API를 수집해야만 공식 평가를 진행할 수 있다고 조건을 바꾸지 않는다.

## 3. 결과

- **공식 9월 API 재고 평가: 최신 자료 계약에 맞춘 후속 모델은 아직 미실행.**
- H-0004의 11.35%는 3월의 기록 거래 건수 deviance 감소다. 9월 재고·품절 성능이 아니다.
- 2·3월의 실측 재고 정답을 새로 얻었거나 복원 재고를 실측으로 승격한 사실은 없다.

**다음 행동:** 과거 이력 학습 모델을 미래 상태 예측에 연결할 후보와 단순 재고 유지 기준선을 정리하고,
9월 API를 공식 평가로 하는 새 가설·입력/정답·예측 시간·표본·지표·판정 규칙을 실험 전에 동결한다.
최근 거래 이력을 입력으로 제안할 때도 9월 검증 시 실제로 확보 가능한 정보인지 먼저 확인한다.
9월에 없는 거래 이력을 0으로 만들어 넣거나, 2·3월 보조 점수로 공식 성능 보고를 대신하지 않는다.
