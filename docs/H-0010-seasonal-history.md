# H-0010 대여소별 계절 패턴을 배우는 예측 모델

## 가설

더 넓은 과거 이력에서 대여소별 월·요일·시간대 패턴을 계층적으로 평활하고 작은 GCN으로 보완하면,
같은 넓은 이력의 비계절 달력 모델과 고정 H9 융합 모델보다 30분 뒤 재고 분포 예측을 개선할 수 있는가?
두 대조군 대비 전체 CRPS 상대 감소의 최소값이 1%를 넘고 3일·7일 블록 구간의 하한도 1%를 넘어야 지지한다.
모델의 크기와 FM을 동시에 바꾸지 않고 학습 기간과 대여소별 계절 표현을 우선 비교한다.

[Lin 외 저자 원고](https://arxiv.org/pdf/1712.04997)의 시공간 거래 예측과
[Gammelli 외](https://arxiv.org/abs/2108.00858)의 흐름·재고 예측을 참고한다.
최근 거래를 사용하는 recurrent 모형의 입력이 9월에 있다고 가정하지 않는다.
이번 계층 평활과 GCN 잔차는 별도 후보 설계이며 두 논문의 전체 재현이 아니다.

## 실험

원본의 2024-08~2026-01을 학습 후보로 넓히고 2026-02 거래 건수만으로 평활 강도·checkpoint를 고른다.
월 이름이 잘못된 2025-12 자료와 기록 누락·경계일은 제외한다. 기존 학습 대여소 1,192개와 과거 OD를 고정한다.
각 대여소의 첫 학습 거래 이전은 기록 0으로 학습하지 않는다. 이를 실제 운영 개시나 공급 노출의 실측값으로 부르지 않는다.
2026-03은 선택 후 보조 거래 진단이고 실측 재고 정답이 아니다.

비교군은 넓은 이력의 비계절 달력, 월별 계층 평활, 같은 평활 위 자기 대여소 네트워크와 OD-GCN이다.
신규 OD-GCN을 사전 주후보로 지정하고 32폭·1층·각 2시드·20epoch를 사용한다.
정적 달력 입력의 학습을 거래 합계·유효 노출의 충분통계로 계산하고 원래 Poisson 목적과의 등가성을 검사한다.
원본·특성·선택·가중치·모든 월 출력·수치 근사를 잠근 뒤 공식 9월 API로 재고를 평가한다.
현재 시작 상태와 미래 정답은 분리한다. API로 모델·분포·임계값·가중치를 선택하거나 보정하지 않는다.

전체 계획은 [동결 기록](../research/hypotheses/H-0010.json), 출처는 [입력 목록](../research/datasets/tashu-seasonal-history-H0010-v1.json)을 따른다.
학습·전처리·검사·분석은 dislab에서 수행한다. 기존 H7·H9의 부정 결과와 이미 노출된 9월 평가의 한계를 보존한다.

## 결과

계획 동결 단계다. 학습·공식 평가 결과는 아직 없다.
Draft PR과 구현을 게시한 뒤 원본 재집계 → 과거 전용 학습/선택 → 모델 잠금 → 3월 보조 진단 → 9월 공식 평가 순서로 실행한다.
개선 여부와 관계없이 모델·실행 근거·판정을 같은 PR에 남긴다.
