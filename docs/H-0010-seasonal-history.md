# H-0010 대여소별 계절 패턴을 배우는 예측 모델

## 가설

더 넓은 과거 이력에서 대여소별 월·요일·시간대 패턴을 계층적으로 평활하고 작은 GCN으로 보완하면,
같은 넓은 이력의 비계절 달력 모델과 고정 H9 융합 모델보다 30분 뒤 재고 분포 예측을 개선할 수 있는가?
두 대조군 대비 전체 CRPS 상대 감소의 최소값이 1%를 넘고 3일·7일 블록 구간의 하한도 1%를 넘어야 지지한다.
모델의 크기와 FM을 동시에 바꾸지 않고 학습 기간과 대여소별 계절 표현을 우선 비교한다.

[Lin 외 저자 원고](https://arxiv.org/pdf/1712.04997)의 시공간 거래 예측과
[Gammelli 외](https://arxiv.org/abs/2108.00858)의 흐름·재고 예측을 참고한다.
최근 거래를 사용하는 recurrent 모형의 입력이 9월에 있다고 가정하지 않는다.
이번 계층 평활과 GCN 잔차는 별도 후보 설계이며 두 논문의 전체 재현이 아니다.

## 실험

원본의 2024-08~2026-01을 학습 후보로 넓히고 2026-02 거래 건수만으로 평활 강도·checkpoint를 고른다.
월 이름이 잘못된 2025-12 자료와 기록 누락·경계일은 제외한다. 기존 학습 대여소 1,192개와 과거 OD를 고정한다.
각 대여소의 첫 학습 거래 이전은 기록 0으로 학습하지 않는다. 이를 실제 운영 개시나 공급 노출의 실측값으로 부르지 않는다.
2026-03은 선택 후 보조 거래 진단이고 실측 재고 정답이 아니다.

비교군은 넓은 이력의 비계절 달력, 월별 계층 평활, 같은 평활 위 자기 대여소 네트워크와 OD-GCN이다.
신규 OD-GCN을 사전 주후보로 지정하고 32폭·1층·각 2시드·20epoch를 사용한다.
정적 달력 입력의 학습을 거래 합계·유효 노출의 충분통계로 계산하고 원래 Poisson 목적과의 등가성을 검사한다.
원본·특성·선택·가중치·모든 월 출력·수치 근사를 잠근 뒤 공식 9월 API로 재고를 평가한다.
현재 시작 상태와 미래 정답은 분리한다. API로 모델·분포·임계값·가중치를 선택하거나 보정하지 않는다.

전체 계획은 [동결 기록](../research/hypotheses/H-0010.json), 출처는 [입력 목록](../research/datasets/tashu-seasonal-history-H0010-v1.json)을 따른다.
학습·전처리·검사·분석은 dislab에서 수행한다. 기존 H7·H9의 부정 결과와 이미 노출된 9월 평가의 한계를 보존한다.

이는 이미 공개된 같은 평가 범위의 참고값이며 이번 H10의 추가 사전 주비교나 새 유의성 판정은 아니다.
기존 최고 점수를 갱신했다고 주장하지 않고 API 순위로 모델을 선택하지 않는다.

### 실제 학습과 자료 범위

원본 9,320,018행 중 월 불일치 203,545행·기간 이상 8행·중복 2행을 제외한 전체 기간 완료 거래는 9,116,463개다.
이 전체 거래 수를 학습 거래 수로 부르지 않는다. 학습은 그중 2024-08~2026-01의 기록 범위이며 2025-12는 빠진다.
기존 학습 대여소 1,192개에서 첫 기록 이전 399,744개 칸을 제외해 유효 학습 노출 **16,776,976개 대여소×반시간**을 사용했다.
기존 H4 시간 합계·누락 마스크와 새 30분 집계의 일치 검사를 통과했다.

평활 강도는 비계절/계절 모두 2월 거래 기준 alpha=32를 선택했다. GCN은 각 2시드·20epoch를 학습했고 네 checkpoint 모두 epoch1을 선택했다.
GCN 신경망은 시드당 2,146모수이며, 학습한 계절 평활표는 별도다. 신경망 모수 수를 전체 모델 정보량으로 해석하지 않는다.
전처리·학습·선택·보조 진단을 합친 시간은 227.2초다. 동결한 본 실험은 dislab의 RTX 3080에서 수행했다.
검사 8개에서 원 거래와 충분통계의 Poisson 손실·gradient 등가, 미관측 월의 상위 prior 복귀, 첫 기록 이전 마스크,
학습 기간 경계, 실제 최적화를 확인했다. 연구 프로토콜 검사 14개도 통과했다.

### 과거 거래 진단과 다음 개선

| 모델 | 3월 보조 거래 Poisson deviance↓ |
|---|---:|
| 넓은 이력 비계절 달력 | 0.952914 |
| 대여소별 계절 평활 | 0.957149 |
| 계절 평활 + 자기 대여소 | 1.017692 |
| 계절 평활 + OD-GCN | 1.015875 |

이 표는 기록 건수의 보조 진단이다. 2·3월 실측 재고 정답을 얻은 결과가 아니다.
GCN은 2월 선택 지표를 조금 낮췄지만 3월 건수 지표는 계절 평활보다 높았다.
한 달의 선택이 다른 계절의 일반화를 보장하지 않는다는 제한을 확인했으며, 이것만으로 원인의 기여량을 식별하지는 못했다.

다음 개선 질문은 **과거 여러 계절을 순서대로 검증하는 시간 분할과 장기간 예측 공백의 대응**이다.
학습 마감부터 공식 9월까지 최근 거래·동시 날씨가 들어오지 않는 제약을 모델 크기로 해결했다고 주장하지 않는다.
계절별 과거 검증·가용한 현재 맥락·분포 학습을 구분해 새 가설로 좁힌다. 9월 API로 현재 가중치·혼합·보정을 다시 맞추지 않는다.

### 모델 보존과 사용

연구 구현과 사전에 지정한 OD-GCN 모델을 보존한다. API 점수로 운영 모델·서비스 기본값을 선택하지 않았다.
다음 명령의 입력은 수동 시나리오이고 미래 정답이 필요 없다. 시각은 한국시간 정시·30분, 07:00~21:30을 지원한다.

```bash
python research_code/seasonal_history.py predict --artifacts PRIVATE_MODEL_ARTIFACTS --station-id ST0003 --parking-count 4 --issued-at 2026-10-31T15:00:00+09:00
```

출력은 30분 뒤 평균·중앙값·0대 확률·5~95% 분위수다. 과거의 완료 흐름과 현재 표시 재고를 연결하는 근사이며,
실제 정상 자전거·운영자 재배치·물리적 주차 용량과 미충족 수요를 직접 예측한 것으로 해석하지 않는다.
9월은 이미 여러 번 열람한 공식 평가 자료이고 독립 미열람 시험이 아니다. 블록 구간에는 학습·선택 불확실성이 모두 포함되지 않는다.

계획 게시 `ed954eb6b3fd9477d268c50678d337baea30545c`, 실행 전 구현 `19997dbb223b922ecb31f7474e722a3e8cab196f`.
[학습 기록](../research/runs/H-0010-20261031-seasonal-history/training.json)과 [실행 manifest](../research/runs/H-0010-20261031-seasonal-history/manifest.json)에 해시·환경·시드·지표를 연결한다.
원본·개별 관측·가중치는 공개하지 않는다. 이후 연산 장소 전환은 기존 동결 계획과 본 실험의 실행 사실을 소급 변경하지 않는다.
