# 타슈 공모전 IR 발표자료

[편집 가능한 12장 발표자료](https://chatgpt.com/space/page_bf09fd9c24888191bfa64c56cea45780) · [2분 시연 영상](../assets/demo/tashu-demo-2min.mp4) · [기존 워크시트](https://chatgpt.com/space/page_368cb7d489f08191b37bf51fbca914bf)

발표자료는 뷰어에서 PPTX로 내려받을 수 있다. 글자·도형·설문 그래프와 서비스 구성도를 편집할 수 있다. 실제 화면 캡처는 개별 이미지다. 기존 워크시트의 다른 내용은 유지하고 8번 구성도의 표현을 ‘10분 뒤 자전거가 부족할 대여소’로 고쳤다.

## 발표 순서

| 장 | 내용 | 심사 항목 |
|---|---|---|
| 1–2 | 대전의 빈 대여소와 운영자의 공급 순서 결정 문제 | 발표주제의 적절성 |
| 3 | 이용 불편 설문 10건의 집계 | 발표주제의 적절성 |
| 4–6 | 편집 가능한 서비스 구성도, 실제 시연, GCN·포아송·FM 역할 | AI 개발 및 구현의 적합성 |
| 7 | 9월 평가의 분포 오차와 수량 오차 | AI 개발 및 구현의 적합성 |
| 8–9 | 한 권역·차량 1대의 4주 시범 운영, 도입·비용 구조 | AI 기술 및 서비스의 실현가능성 |
| 10–11 | 환승 거점 화면 연계 예시, 다른 권역·도시로의 확장과 현장 협력 | 해당 분야의 파급효과 |
| 12 | XGBoost·GCN, FM의 추가 이득, 미충족 수요에 관한 질의응답 | 질의응답 |

각 심사 항목은 25점이라는 사용자 제공 기준을 반영했다. 발표자 설명과 원문 링크는 슬라이드 노트에도 넣었다. [노트 원문](../design/ir-speaker-notes.json)과 [작성 소스](../design/ir-deck-editable.mjs)를 함께 보존한다.

## 설문을 반영한 내용

제공된 설문은 응답 10건이다. 연락처·개별 시각·자유 응답 원문을 내보내지 않고 dislab에서 집계했다. 신원 중복 제거와 모집 방식 확인은 하지 않았다.

| 항목 | 응답 수 |
|---|---:|
| 0대라 헛걸음: 주 1,2회 | 4건 |
| 0대라 헛걸음: 주 3,4회 | 4건 |
| 0대라 헛걸음: 거의 매일 | 1건 |
| 0대라 헛걸음: 월 5회 미만 | 1건 |
| 없을 때 버스·지하철 또는 도보로 전환 | 4건 |
| 다른 공유 자전거·킥보드로 전환 | 3건 |
| 인접 대여소로 이동 | 2건 |
| 이동 포기·연기 | 1건 |
| 반납할 자리가 없어 곤란했던 경험: 예 | 5건 |

주 1회 이상 또는 거의 매일이라는 응답은 4+4+1=9건이다. 비율을 대전시민 전체로 확대하지 않고 불편 사례를 보여주는 자료로 사용한다. 구매 의사나 운영기관의 도입 의향을 묻지 않았으므로 시장 검증·계약 근거로 쓰지 않는다. API 재고로 관측하지 못한 실제 대여 포기 인원을 이 설문과 합쳐 추정하지도 않는다.

[집계 JSON](../design/survey-summary.json) · [재현 코드](../tools/summarize_survey.py). 원본 CSV SHA-256은 `b7e0a28f2338ff49995de1cd0f3f710ff452f8087e9602a2ff53f24e3cb31b24`다. 원본과 연락처는 공개 저장소에 넣지 않았다. 이 집계는 발표를 위한 기술통계이며 H27 외부 LLM의 동결 입력이나 모델 선택 자료를 바꾼 것이 아니다.

## 성능·운영 수치의 구분

발표의 15.22%는 9월 공식 재고 평가에서 현재 재고 유지 대비 FM의 fairCRPS 감소다. 수량 MAE는 거의 같으며 포아송 대비 FM 추가 이득은 확인되지 않았다. 모델은 H13으로 유지한다.

시연의 5대·8곳·5.26km·9.1분은 2026년 11월 10일 20:50 기록과 가정한 차량 조건에서 계산한 계획이다. 실제 이동 완료나 비용 절감률이 아니다. 현장 효과는 4주 시범 운영에서 실제 주행·작업 시간·계획 채택률로 확인하도록 구성했다.

## 지역 문제와 기술 출처

- [대전시 2024.05.28 발표](https://daejeon.go.kr/drh/drhStoryDaejeonView.do?boardId=blog_0001&menuSeq=&ntatcSeq=1457244726&pageIndex=1): 반납·재배치 불편과 운영 인력 확충 계획, 환승 연계 설명. 당시의 2026년 운영 목표를 현재 운영 규모로 인용하지 않는다.
- [GCN 원문](https://arxiv.org/abs/1609.02907), [Flow Matching 원문](https://arxiv.org/abs/2210.02747): 표현과 개념의 참고. 현재 구현의 상세 역할은 [고정 H13 결과](H-0013-rolling-api-flow.md)와 [서비스 구성도](service-composition.md)를 따른다.

새 교통 특징을 모델에 추가하지 않았다. 버스·도시철도 연계는 우선 운영 화면에서 확인하는 예시이며 별도의 입력 통합 실험을 완료한 것처럼 표시하지 않는다.
