# 제안 아키텍처의 타당성 검토

검토일: 2026-10-31. 대상은 기존 `multimodal_transit_flow_matching.py`와 관련 전처리다.
기존 결과표는 재현된 근거로 사용하지 않았다. 이 문서는 코드에서 확인한 사실과 새 실험의 범위를 구분한다.

## 현재 판단

시간 이력·주변 대여소·확률 예측을 결합하려는 방향에는 검증할 이유가 있다.
그러나 기존 Transit-CFM 전체를 현재 API 재고 문제에 타당하다고 판정할 수는 없다.
입력·정답·평가를 맞춘 작은 비교부터 수행한다. 해당 실험은 [H-0002](../research/hypotheses/H-0002.json)에 등록한다.

후속 [H-0002 결과](H-0002-architecture-results.md): dislab의 세 시드 비교에서 소형 그래프 CFM의 추가 가치를 지지하지 않았다.
현재 양수 표본의 Brier는 자기 이력 0.079564, 좌표 그래프 직접 예측 0.078826, CFM 0.082581이었다.
좌표 그래프의 작은 평균 개선도 보조 날짜 구간이 0을 포함하므로 확정적인 추가 가치로 설명하지 않는다.

| 구성 | 코드에서 확인한 근거 | 판단과 검증 방법 |
|---|---|---|
| 정답과 시점 | loader 120~124행은 `rentals`, `returns`, 복원 `inv_start`, `od`를 요구한다. 새 API 정답은 `parking_count`다 | 실제 거래량 예측과 재고 상태 예측은 다른 문제다. 원래 두 출력 모델을 API 재고에 그대로 학습하지 않는다 |
| 복원 재고 | `preprocess.py` 200~245행은 같은 자전거의 다음 대여 시각·장소를 보고 과거 정차 구간을 구성한다 | 사후 복원 하한은 당시 온라인에서 알 수 있던 API 재고와 다르다. 이를 온라인 입력으로 쓰는 평가에는 미래 정보가 섞일 위험이 있다 |
| 공간 그래프 | loader 124·314행은 입력 NPZ의 OD를 그대로 사용한다. `preprocess.py` 284행은 입력 거래 전체로 OD를 만든다 | 기본 경로에서 시험 거래가 그래프에 들어갈 위험이 있다. train-only OD 도구는 별도로 있지만 loader가 자동 사용하지 않는다. 과거 실제 실행의 입력 생성 이력은 미검증이다. 새 비교에는 첫날 좌표 기반 고정 그래프를 쓴다 |
| 대중교통 정보 | 218~260행은 대여소 이름의 키워드로 버스 거점을 정하고 거리를 만든다. 첨두 파형도 고정 가정이다 | 실제 버스 승하차·운행 장애를 관측한 결합이 아니다. 정적 주변 정보 가설로 검증해야 한다 |
| 날씨 | 284~300행은 대상 시간의 실측 날씨를 읽고, 일치 시각이 없으면 첫 항목으로 대체한다 | 미래 예측에는 발행 시각이 보존된 예보나 당시까지의 관측만 써야 한다. 잘못된 시각 대체도 수정 대상이다. 이번 최소 비교에서는 날씨를 제외한다 |
| Flow Matching 목적함수 | 543~555행은 독립 Gaussian 초기값과 `log1p` 정답 사이의 직선 경로를 회귀한다 | 기본적인 독립 결합 CFM 형태로 해석할 수 있다. 직선 경로만으로 분포 사이의 최적 수송 계획을 계산했다고 할 수 없다 |
| 예측 초기값 | 학습은 Gaussian, 기본 `solve_ode` 564행은 0에서 출발한다 | 0 초기값에서 나온 한 경로가 조건부 평균·중앙값이라는 보장은 없다. 확률은 학습과 같은 초기 분포의 반복 표본으로 평가한다 |
| 연속 시간 | 내부 적분 시각은 0~1의 생성 경로 매개변수다 | 물리적 자전거 이동 시간이나 보존 법칙이 아니다. ODE를 쓴다는 이유로 도시 내 실제 재고 흐름을 설명한다고 해석하지 않는다 |
| 정수와 0대 | 연속 `log1p` 생성 후 `expm1`·음수 절단을 쓴다 | 정수 재고의 확률과 0대 확률을 정의해야 한다. 새 비교는 균등 dequantization과 정수 복원 규칙을 고정한다 |
| 정책 시뮬레이션 | 667~716행은 입력 재고·첨두 파형을 바꾼 예측의 차이를 정책 결과처럼 서술한다 | 입력 민감도는 인과 효과와 다르다. 개입 식별 가정·운영 제약·현장 정답 없이 재배치나 지하철 장애의 효과를 입증할 수 없다 |

## 선행 근거와 확인 범위

- [Lipman 외, Flow Matching](https://arxiv.org/abs/2210.02747): 저자 초록·확률 경로 설명을 확인했다. 생성 모형의 근거이며 타슈에서의 유효성을 입증한 연구가 아니다.
- [Tong 외, 2024, §3.2.2~3.2.3](https://arxiv.org/html/2302.00482v4): 독립 결합 CFM과 OT-CFM의 구분을 원문에서 확인했다. 현재 구현에는 미니배치 OT 결합 계산이 없다. 점에 조건부인 직선 경로와 주변 분포의 최적 수송을 구분한다.
- [Nejadshamsi 외, 2026](https://doi.org/10.1016/j.knosys.2025.114986): 출판사 검색 노출 방법에서 공간·시간 이력 결합과 거래량 정답을 확인했다. 공간 정보를 시험할 동기는 되지만 재고 문제에서의 추가 가치는 별도다.
- [Gammelli 외, 2022](https://arxiv.org/abs/2108.00858): 예측과 재고 의사결정을 연결한 저자 원문. 이번 API 예측 비교는 운영 효과 검증을 대체하지 않는다.

## 이번에 실제 비교할 범위

관측 재고에 맞춘 작은 모형으로 공간 결합과 CFM의 필요성을 점검한다.
현재~50분 전의 6개 재고 관측·누락 표시·시간·첫날 좌표·대여소 임베딩을 입력으로 하고,
30분 뒤 관측 0대 확률을 예측한다. 현재 양수인 표본의 Brier score를 주 지표로 삼는다.

비교군은 현재 상태 유지, 학습 기간 빈도, 자기 이력 분류기, 좌표 그래프 분류기,
대여소 연결을 섞은 그래프 분류기, 그래프 CFM이다. 3개 학습 시드를 사용한다.
CFM은 재고 하나를 생성하며 원래의 대여·반납 두 출력 아키텍처를 그대로 재현한 것은 아니다.
주변 정보의 추가 가치와 CFM의 추가 가치를 같은 미래 관측에서 분리해 본다.

모형 폭·깊이·학습량은 소규모로 고정한다. 원래 6층·512폭 모델이나 대중교통·서울 전이 전체에 대한
긍정·부정 판정으로 확대하지 않는다. 제한된 계산량에서의 첫 반증 실험이다.
전체 계획·표본·제외·판정 기준은 H-0002의 동결 JSON이 기준이다.
