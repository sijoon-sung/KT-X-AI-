# H-0006: 수량 오차의 원인을 손실·결정·분포로 나눠 확인

## 1. 가설

같은 과거 전용 재고 분포라도 평균 대신 MAE에 맞는 하위중앙값을 출력하면 공식9월의 전체 MAE가 0.01대 넘게 줄어들 것이다.
이는 새 아키텍처 우승자를 고르는 비교가 아니라 **평가 손실과 점출력의 일치**를 점검하는 실험이다.
[Gneiting2011 저자 원문 §1.3·Table5](https://arxiv.org/pdf/0912.0902)에서 제곱손실↔평균·절대손실↔중앙값을 확인했다.
모형 자체 분포에서 최적인 결정도 실제 자료에서 좋다는 보장은 없다.

H-0005의 평균 출력 MAE 악화를 전체 분포 실패로만 해석하지 않는다.
그 결과를 본 뒤 이론적 점검을 추가했다는 사실을 공개한다. 공간 비교는 후보로 유지하되 이 해석 문제를 먼저 분리한다.

## 2. 실험

학습·사건률·분포는 H-0005와 동일하게 고정한다. API 학습·보정·분위수/모형/구조/손실 선택은 없다.
평균은 MSE/RMSE, 하위중앙값은 MAE, 0대 확률은 Brier, 분포는 CRPS와 고정 분위수 포함률로 나눠 보고한다.
평균·중앙값을 한 모델의 서로 다른 요약으로 취급하며 API에서 승자를 골라 새 분포로 바꾸지 않는다.

- 자료: 과거 전용 고정 모델, 공식9월 API. 현재 관측은 시작 상태, 미래 관측은 정답만 제공.
- 현재·목표 모두9월, 실제9/17~30, 정시07~21시·30분뒤, ID/누락/요청시차 계약은 H-0005와 동일.
- 수치: 과거 계수만으로 반복 상한을 정한 동일 포아송 균일화 분포의 전방 재귀. 큰 재고 상한 절단 없음.
- 비교: 현재 유지, 고정 달력 과정 평균, **같은 분포** 하위중앙값(min{k:CDF(k)>=0.5}).
- 주 지표: 전체 공통쌍의 MAE(평균)−MAE(중앙값). 3일/7일 도시 날짜 블록 각2,000회, seed20261031.
- 충분성: ID500·유효쌍100,000·유효날짜10·블록유효복제각1,900 이상.
- 지지: 점추정과 두95%구간 하한 모두>0.01대. 충분성 아래 두상한모두≤0.01이면 지지하지 않음, 나머지는불확실.
- 보조: 중앙값대현재유지 MAE차·구간, 상태별MAE/RMSE/bias, CRPS,5~95%포함률·폭,같은P0의Brier,중앙값유지비율.
- dislab CPU에서 합성 수치/미래누출 검사를 먼저 실행하고 계획·구현 게시 뒤 실제 평가한다.

전체 동결 규칙과 입력 해시는 [가설 기록](../research/hypotheses/H-0006.json)·[입력 목록](../research/datasets/tashu-loss-consistent-stock-H0006-v1.json)에 있다.
9월은 이전 실험과 H-0005에 이미 노출된 공식 반복 평가이며 미열람 독립 시험이 아니다.
사전 기준은 연구 간격이며 서비스 비용의 합의값이 아니다.

## 3. 결과

**계획 시점에는 미실행.** 결과를 본 뒤 분위수·확률·사건률을 API에 맞춰 조정하지 않는다.
기대 MAE와 관측 MAE 차이는 분포의 불일치 단서일 수 있으나 재배치·시즌 변화·관측 지연을 각각 식별하지 못한다.
다음 행동은 이 비교를 먼저 실행하고, 손실/결정 문제와 여전히 남는 분포·공간 문제를 구분해 기록하는 것이다.

**완료 기록:** [H-0006 결과](H-0006-results.md)에 사전 규칙에 따른 실제 비교를 남겼다.
평균→중앙값 MAE 감소 가설은 지지했으나 현재 유지 대비 개선의 두 보조구간은0을 포함한다.
동결 계획과 원래 H5 결과를 유지하고, 모형·확률 개선이나 운영 모델 채택으로 확대하지 않는다.
