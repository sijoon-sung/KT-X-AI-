# H-0005: 과거 흐름을 9월의 미래 재고로 연결하기

상태: 사전 동결·미실행. [가설 JSON](../research/hypotheses/H-0005.json)이 정확한 기준이다.
[아키텍처 아이디어와 비교 순서](architecture-ideas-to-experiments.md)에서 좁힌 첫 질문이다.
이는 최종 아키텍처 채택이 아니라 후속 공간·생성 모듈을 비교할 상태 연결 기준점이다.

## 1. 가설

**고정한 과거 달력 거래율과 현재 API 재고를 연결한 단순 확률 과정이,
현재 양수인 곳의 30분 뒤 0대 확률에서 현재 재고 유지보다 Brier를 0.005 넘게 줄일 것이다.**

[Gast 외, 2015 §2.2~3.1](https://www.pure.ed.ac.uk/ws/portalfiles/portal/23608488/Gast_et_al_2015_Probablistic_Forecasts.pdf)의
현재 상태 조건부 사건 과정에서 아이디어를 가져온다. 해당 원문은 실측 상태에 따른 노출 시간을 사용한다.
우리는 그 과거 재고가 없으므로 **완료 거래율을 유효 사건률로 옮기는 근사**를 별도로 검증한다.
미충족 수요나 원문의 발생률 추정을 재현했다고 주장하지 않는다.

## 2. 실험

### 고정할 모듈과 바꿀 질문

- 과거 학습: H-0004에서 저장한 달력 거래율 모델을 주 후보로, 고정 거래율 모델을 보조 대조로 해시 고정한다.
  H-0004의 11.35%를 재고 성능 근거로 쓰지 않는다. 이번에 새로 학습·보정하거나 9월 점수로 둘 중 선택하지 않는다.
- 상태 과정: 반납률 `a`로 재고 +1, 재고가 양수일 때 대여률 `d`로 −1. 0에서는 대여 시도가 상태를 바꾸지 않는다.
  물리 용량 상한·재배치·노출 보정·공간 의존성은 넣지 않는다.
- 현재 API 재고는 **검증 시작 상태**다. 미래 재고는 정답에만 사용하며, API로 계수를 학습·튜닝하지 않는다.
- 포아송은 여기서 **사건 시도**에 관한 가정이다. 미래 재고 자체가 포아송 분포라는 가정이 아니다.
- 생성기·GCN·FM·기존 API 학습 가중치는 붙이지 않는다. 이 후속 후보들은 별도 가설로 남긴다.

### 공식 평가 자료와 정답

| 항목 | 동결 범위 |
|---|---|
| 공식 기간 | 2026-09-01 이상~10-01 미만. 실제 원본은 9/17~30, 시간대는 KST 조건부 |
| 예측 원점 | 07~21시 매 정시, 현재와 30분 뒤가 모두 9월에 속하는 관측 |
| 관측 계약 | 10분 격자·각 요청 지연 0~120초, 실제 현재/정답 요청 차이 1800±120초 |
| 예측 시간 | 고정 30분. 미래 요청 시각으로 예측 시간을 조정하지 않음 |
| 대여소 | 과거 모델 ID와 API ID 문자열의 정확한 교집합. 미래 값으로 대상 선택 안 함 |
| 주 지표 | 현재 양수 공통 관측쌍의 `Brier(현재 유지)−Brier(달력 과정)` |
| 주 대조 | 현재 재고 유지: 재고 평균은 현재값, 0대 확률은 현재가 0일 때만 1 |
| 보조 | 고정 거래율 과정, 현재 0/양수/전체 Brier·재고 평균 MAE·고정 확률 구간별 관측 빈도 |

누락은 0이 아니다. 현재·정답 시각의 유효성과 ID 대응/제외 수를 함께 보고한다.
기존 패널과 원본 목록의 해시를 검사하되 이전 44일 목록을 다시 쓰거나 10월로 평가를 확장하지 않는다.
[새 입력 manifest](../research/datasets/tashu-history-to-stock-H0005-v1.json)에 과거 모델과 9월 자료의 역할을 분리했다.

### 수치 계산과 불확실성

과거 거래율만으로 포아송 반복 횟수의 꼬리 허용오차를 정하고, API를 읽기 전에 전이표를 만든다.
낮은 상태는 후방 재귀, 수치 표 범위보다 큰 초기 재고는 꼬리 경계가 보장되는 식을 쓴다.
표의 끝을 물리적 재고 상한으로 쓰지 않는다. 허용오차·최대 반복 수 게이트 실패는 기록하고 임의로 조정하지 않는다.
해석 가능한 순수 도착·순수 출발과 작은 행렬지수 비교로 합성 검사를 한다.

9/17~30의 14개 원본 달력 날짜를 도시 동기화한 3일·7일 이동 블록으로 각 2,000회 재표집한다.
날짜별 두 Brier 손실 합·양수 쌍 수를 같이 다루며, 부분 날짜·빈 날짜를 삭제해 인접시키지 않는다.
seed20261031·PCG64. 과거 거래율의 추정 불확실성은 이번 구간에 포함하지 않는다.
모든 연산은 dislab에서 수행한다.

## 3. 결과

**사전 계획의 판정 규칙:** 매칭된 과거 학습 ID 500개·현재 양수 10,000쌍·유효 날짜 10일·각 블록 유효 복제 1,900회 이상을 요구한다.
주 개선 점 추정과 두 95% 구간 하한 모두 >0.005이면 지지, 자료 충분성 아래 두 상한 모두 ≤0.005이면 지지하지 않음,
그 밖에는 불확실이다. 0.005는 사전 연구 간격이며 현장 합의값이 아니다.

이전 API 실험에 9월이 노출됐다는 사실을 기록하며 미열람 독립 시험으로 부르지 않는다.
완료 거래율의 수요 절단·과거와 9월의 수준 변화·무기억/독립 가정·재배치 미관측·ID 변경·관측 지연이 한계다.
성공해도 GCN·FM이나 전체 도시 결합 분포의 필요성까지 결론 내리지 않는다.

계획 시점의 다음 행동은 Draft PR·계획·구현 게시와 합성·자료 경계 검사 뒤 9월의 미래 API 정답으로 이 연결을 평가하는 것이었다.
결과를 본 뒤 9월에 맞춰 사건률·보정·예측 시간·임계값을 바꾸지 않는다.
