# 승인된 API의 실시간 관측과 고정 예측 검증 · H-0018

## 가설

새로 승인된 키의 재고 API를 현재 관측→동결 모델 예측→다음 관측 채점으로 연결할 수 있는지 검증한다.
새 모델 우월성·운영 효율·0대 대여소의 미충족 수요를 해결했다는 가설은 아니다.
[PR25](https://github.com/sijoon-sung/KT-X-AI-/pull/25)에 계획을 `9b9eda1ee98d7c95b000a80c26eaa23026a4909f`로 먼저 동결·게시했다.
승인 키의 연결 확인은 별도 사전 연결검사이며 학습·성능 비교에 쓰지 않았다.

## 실험

### 인증과 자료 역할

[타슈 공식 FAQ](https://www.tashu.or.kr/faqList.do)의 GET·api-token 헤더·대여소 스키마를 확인했다.
인증키는 표준입력/메모리 채널로 전달하고 dislab Windows 계정에 묶인 DPAPI 암호문으로 비공개 보관했다.
키 값·원본 API·개별 예측·접속정보는 공개 파일에 넣지 않는다. 인증키를 재출력하지 않는다.

공식9월 평가는 그대로 유지한다. 이 실시간 자료는 별도 추가 검증이며 다음 관측을 과거 입력으로 소급하지 않는다.
가중치·그래프·정규화·모형/분포/임계값 선택·보정·학습 입력 재사용은 하지 않는다.
H13의 기존 모델 lock·12개 핵심 코드·artifact 해시를 확인하고 GCN+FM과 같은 Poisson·현재유지·추세 비교군을 그대로 사용했다.
H13의 원래 학습 위치 위반과 H14의 실패 판정도 바꾸지 않는다.

### 수집·시계·자원

수집·추론·채점·계획은 모두dislab에서 실행한다. 로컬은 결과 파일 동기화·표시와 원격 stdin 전송만 한다.
핵심 실행 코드는 `fa19e76dab7fbe832ce6e8f133c1261e9f072f54`다.
수집은10분 격자, 최대24시간 또는143회다. 앞선 새 키 연결검사1회와 합쳐144회 이내의 작은 시험 예산이며 제공자의 실제 일일 한도라고 단정한 수치는 아니다.
401/403/429는 즉시 중단하고 연속 통신 실패3회도 중단한다. 리다이렉트로 키를 다른 주소에 보내지 않는다.

원격 OS 시계가 약139.524초 느려서 시작 전 수집기 왕복 중간값으로 보정했다. 불확실성은0.616초이며2초 한도 안이었다.
그 뒤 관측·발행·미래 정답에는 같은 단조시계 기반UTC를 사용한다. native 시각과 기준 시각을 구분한다.
관측 지연0~120초·미래 실제 경과480~720초만 채점하고 누락을0대로 바꾸지 않는다.
첫 회차의 이전 관측 부재는 결측 마스크로 표시한다. 다음 회차부터 실제 직전10분 관측을 사용한다.
기상은 기존 아카이브와 원래 결측 표시이며 실시간 기상이 연결됐다고 하지 않는다.

### 화면과 재배치 경계

실제 관측의 source_version과 예측 대상 시각을 함께 표시하고, 다음 관측이 없으면 점수는 대기 상태다.
최근 검증에서 GCN+FM/현재유지 수량MAE, 현재0/양수 그룹,0→양수·양수→0 전환을 구분한다.
이는 API 표시 재고의 변화이며 반납·재배치·수리·잠재 수요를 분리한 정답이 아니다.
현재0대여소에대해 대여에실패한사람수나실제미충족수요를새로관측한것은아니다.

관측 버전이 바뀌면 지도 입력과 계획을 다시 계산한다. 이전 응답은 버리고 다른 버전의 입력은409로 거부한다.
관측이720초 이상 오래되면 계산을 막고 화면도 갱신 지연을 표시한다.
수량·경로는 **관측 시점을 출발점으로 한 가정 계획**이며 실제 현재 출동·GPS·현장 효과가 아니다.
H17의 선택후보5곳·1차량·가정 자원 안의 계산을 사용하고 모델의 실제 예측 우월성을 추가로 주장하지 않는다.

## 결과

새 키 연결검사는 HTTP200과1378개 대여소·예상 스키마를 확인했다.
14:40 API 관측을 받고14:40:05에1296개 지원대여소의14:50 예측을 발행했다. 현재0대는546곳이고 첫회차이전입력은결측이다.


**14:50 실제 관측으로 최초 인과 회차를 채점했다.** 확인 시점에 수집기는 계속 실행 중이다.

| 최초 추가 회차 | 실제값 |
|---|---:|
| 유효 예측·미래 관측 대응 | 1296개 |
| GCN+FM 수량 MAE | 0.034722대 |
| 현재유지 수량 MAE | 0.034722대 |
| GCN+FM 0대 Brier | 0.012096 |
| 현재0대 그룹 표본 | 546개 |
| 현재양수 그룹 표본 | 750개 |
| 관측0→양수 / 양수→0 | 5 / 2곳 |

초기 회차는 직전 입력이 결측이었던 경우다. 수치 차이를 새 모델의 우월성이나 0대의 미충족 수요 해결로 해석하지 않는다. 이어 발행한 다음 예측은 실제 직전10분 관측을 사용했다.


- 원격 의미 검사8개 통과: 시계/불확실성,0회복 그룹,누락,키 리다이렉트 방지,만료시계,버전 불일치와 오래된 입력 거부.
- 최초 네이티브stderr 처리 때문에 중단된 부분 검사 로그는 보존하고, 별도 전체8검사의 성공 로그를 연결했다.
- SSH 세션 종료와 함께 끝난 최초 분리 실행은 관측을 수집한 것으로 세지 않았다. 현재는 관리되는 세션에서 수집기를 유지한다.
- 로컬 표시 서버의 숨김 실행이 자동 승인 검토에서 거부돼 관리되는 미리보기 세션으로 제공했다. 원래 종료된 서버에 연결 실패한 첫 브라우저 시도도 성공으로 세지 않았다.
- 재시도한 실제 화면에서 API출처/예측시각/점수대기/실제버전전송/원격재계산/연구섹션없음/예외없음을 확인했다.

실행 상태·최초 실제 채점·범위는 `research/runs/H-0018-20261101-live-api/`에 연결한다.
서비스는 최대24시간 시험 수집이며 영구 운영/재부팅 자동 시작을 설정하지 않았다.
주소는 `http://127.0.0.1:8770/dispatch`다. 수집 중지나 노후 관측은 정상 실시간 자료로 설명하지 않는다.
