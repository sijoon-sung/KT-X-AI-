### 해석과 다음 행동

[DeepAR §3.1](https://arxiv.org/pdf/1704.04110)의 NB2는 `Var(Y|x)=μ+αμ² (α≥0)`이며,
포아송 직접 관측 분포는 `Var(Y|x)=E(Y|x)`다.
단순히 재고가 정수라는 이유로 이 분포를 기본 출력으로 고정하면 이번 저산포 구조를 표현하기 어렵다.
[Shmueli 외, 2005](https://doi.org/10.1111/j.1467-9876.2005.00474.x)의 CMP처럼
분산을 유연하게 표현하는 계수형 분포는 비교 후보가 되지만, 이번에는 적합·성능·계산 비용을 검증하지 않았다.

여기서부터는 **분포 가정에서 도출한 수학적 해석**이다.
더 풍부한 조건 H에서 포아송이고 이를 대여소·현재 재고 C로 묶는다면 총분산 법칙에 의해
`Var(Y|C)=E(λ(H)|C)+Var(λ(H)|C)≥E(Y|C)`다.
따라서 더 큰 GCN이나 생성 모형으로 λ만 유연하게 만든 포아송 혼합도 이론적으로는 저산포 해법이 아니다.
단, 이번 유한·의존·선택 표본의 비율을 모집단 모멘트의 확정값으로 동일시할 수는 없다.

반면 포아송 **사건률/혁신항**은 다른 문제다. 예시로,
`Y|b = Binomial(b,p)+Poisson(λ)`에서 두 항이 조건부 독립이면
`E(Y|b)=bp+λ`, `Var(Y|b)=bp(1−p)+λ`로 평균보다 작은 분산이 가능하다.
이는 가능한 계수형 전이의 수학적 예시다. 실제 남은 자전거·반납·대여의 정답이나 물리적 메커니즘을 확인했다는 뜻은 아니다.
용량 경계·운영자 이동·관측 지연도 아직 포함하지 않았다.

| 큰 선택 | 이번 증거로 좁히는 부분 | 여전히 필요한 근거 |
|---|---|---|
| 직접 관측 분포 | 포아송·NB2를 자동 기본값으로 고정하지 않고 분산 유연한 계수형 분포와 비교 | 시간·상태별 예측 분포 보정, 0대·꼬리, 시간 분할 평가 |
| 상태 전이 표현 | 현재 재고의 지속성과 변화 폭을 명시하는 통계적 전이 계열을 후보에 포함 | 단순 상태 빈도·직접 분포 대비 가치, 경계·희소 상태·시간 범위 |
| GCN | 관계를 제공할 수 있는 인코더 후보라는 위치 유지 | 자기 이력·도시 공통 시간 정보 대비 추가 정보와 그래프 안정성 |
| Flow Matching | 결합 시나리오가 필요한 경우의 생성 후보라는 위치 유지 | 단순 결합 기준선, 정수 표현·조건부 prior, 결합 보정·비용 |
| 거래·수요·정책 과정 | 현재 결과로 과정별 발생률이나 인과 효과를 식별하지 않음 | 거래·운영 로그 또는 명시적 식별 가정·검증 |

다음 단계는 **같은 정보·출력에서 직접 재고 분포와 현재 상태에 조건부인 전이 표현을 비교할 이유**를
문헌 카드와 평가 계약으로 구체화하는 것이다. 지속성·0대·전환·분포 보정을 함께 평가하고,
한꺼번에 그래프와 생성기를 바꿔 원인을 구분할 수 없게 만들지 않는다.
아직 H-0004의 계획·예산·모형·판정 규칙을 동결하거나 학습을 시작하지 않았다.
