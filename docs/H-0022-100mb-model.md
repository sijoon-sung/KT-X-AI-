# 약100MB 모델 확장

## 가설

실제 학습 가중치90–110MB의 GCN·Flow Matching을 만들고 과거3월 거래 분포 점수를 기존H13과 비교한다. 정적 특징표·최적화 상태·파일 채우기는 모델 크기에 포함하지 않는다.

## 실험

동결 계획은 `research/hypotheses/H-0022.json`이다. dislab에서 과거 이력만 학습한다. 2월로 체크포인트를 선택하고 3월로 비교한다. 9월API는 가중치를 고정한 뒤 평가에만 쓴다.

GCN 폭1280·은닉층4개, FM 조건망1280·3개층과128차원 속도장을 사용한다. FM 조건망은 대여소별 한 번 계산해 ODE 단계마다 반복하지 않는다. 시드11·29의 두 모델을 함께 배포한다.

## 결과

미실행. 계획을 GitHub Draft PR에 게시한 뒤 시작한다. 기존H13 및 홈페이지 성능은 새 모델 결과로 바꾸지 않는다.
