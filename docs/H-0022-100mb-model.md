# 약100MB GCN·Flow Matching 모델

## 가설

실제 학습 가중치90–110MB로 확장하면 기존H13보다3월 거래 분포의 energy score가1% 이상 개선되는지 비교했다. 사전 계획은 PR32의`ee101cc`에서 게시했다. 정적 특징표·최적화 상태·파일 채우기는 크기에 포함하지 않았다.

## 실험

dislab RTX3080에서 과거 대여·반납으로 학습했다. 2024년8월~2026년1월 학습, 2월 고정131072노출로 체크포인트 선택, 3월16384노출로 비교했다. 시드11·29, GCN16epoch·FM20epoch, epoch당262144노출·batch1024·FP32를 사용했다. 두 시드의 GCN은5/3epoch, FM은19/18epoch가 선택됐다. 배포하는 모든 텐서가 초기화 후 갱신됐는지 검사했다.

GCN 폭1280·은닉층4개, FM 조건망1280·3개층→128차원과128차원 속도장을 사용했다. FM 조건망은 대여소별 한 번 계산했다. 128개 독립 seed-mixture 표본을16단계Heun으로 생성했다. 최적수송 결합·도시 공동분포·RL은 아니다.

가중치와3월 판정을 고정한 뒤9월17–30일의1,298개 대여소·2,458,501관측쌍을 순서대로 평가했다. 현재·직전 관측으로 발행하고 다음 유효 관측으로만 채점했다. API 학습·튜닝·선택은 없었다. 9월은 이미 여러 번 사용한 평가 자료다.

학습 코드`3fb897c7fd6cbb6feb63e6059a3bb0e940b5c918`, 평가 코드`a6bb8b98fbe4d75781412103e90d4e481947562f`. [실행 근거](../research/runs/H-0022-20261102-large/manifest.json)에서 입력·계획·결과 해시와 환경을 확인할 수 있다.

## 결과

실제 체크포인트 합계는 **97,004,358바이트(97.00MB)**, FP32 텐서는96,982,560바이트, 매개변수는 **24,245,640개**다. 시드별48,502,179바이트이며 두 체크포인트를 함께 사용한다. GCN은시드별6,988,994개, FM은5,133,826개다. 약200MB의 과거 특징표는 별도다.

| 3월 완료 거래 분포 | energy score ↓ |
|---|---:|
| 기존H13 FM | 0.1562834 |
| 확대FM | 0.1571943 |
| 확대GCN Poisson | 0.1520845 |

확대FM의3월 점수는0.58% 악화했다. 상대개선율95%구간은3일블록−0.875~−0.321%,7일블록−0.879~−0.335%였다. 사전 개선 가설을 지지하지 않았다. 학습 후반2월deviance가 상승해 초기epoch가 선택됐다. 학습량·조건망도 달라져 크기만의 원인으로 단정하지 않는다.

| 9월10분 재고 | fairCRPS ↓ | 중앙값MAE(대) ↓ |
|---|---:|---:|
| 현재 유지 | 0.212015 | 0.212015 |
| 기존H13 FM | 0.179756 | 0.211982 |
| 확대FM | 0.180022 | 0.211755 |
| 확대GCN Poisson | 0.180007 | 0.211687 |

확대FM의fairCRPS는현재유지보다15.09%감소했고 기존FM보다0.15%높았다. 수량MAE와분포점수는 서로 다른 지표다. API 점수로 다시 모델을 선택하지 않았다.

CPU·GPU5대여소 합성 예측, 실행 전후 파일 검증, HTTP·입력경계14개, 캐시·반복예측4개 검사를 통과했다. CPU5대여소 예측 한 번은0.112초였으며 운영 지연보장은 아니다. 합성 검사는 정확도 평가와 구분한다.

확대 모델은 [별도 릴리즈](https://github.com/sijoon-sung/KT-X-AI-/releases/tag/h22-100mb-v1.0.1)로 제공하고 기본 모델·관리자 화면은H13을 유지한다. [실행 안내](quickstart-h22.md)와 [모델 카드](model-card-h22.md)를 따르며 다음 개선은 새 가설에서 과적합과분포손실을 분리해 비교한다. 차량 운영 효과는 측정하지 않았다.
