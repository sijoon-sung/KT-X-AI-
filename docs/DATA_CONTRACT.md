# 시간별 입력 규약

CSV 한 행은 대여소 하나의 한 시간입니다. UTF-8/UTF-8 BOM, 건/대 단위, 한국 시간을 씁니다.

| 열 | 필수 | 의미 |
|---|---|---|
| timestamp | 예 | 구간 시작 정시 |
| station_id | 예 | 문자열 대여소 ID |
| rentals / returns | 예, 값은 비워도 됨 | [timestamp, timestamp+1시간) 관측 거래 건수 |
| stock | 아니오 | timestamp에 측정한 **구간 시작 재고**. 미측정은 빈칸 |
| lat / lon | 예 | 위도/경도. 같은 ID에서는 일정 |
| name | 아니오 | 표시 이름 |
| capacity | 아니오 | 확인된 수용 상한. 모르면 빈칸. 같은 ID에서는 일정 |

```csv
timestamp,station_id,name,rentals,returns,stock,lat,lon,capacity
2026-01-01T08:00:00,A,예시 A,2,1,3,36.350,127.380,
2026-01-01T08:00:00,B,예시 B,0,2,0,36.351,127.381,
2026-01-01T09:00:00,A,예시 A,1,0,2,36.350,127.380,
2026-01-01T09:00:00,B,예시 B,1,0,2,36.351,127.381,
```

이 4행은 형식 예시이며 학습에는 부족합니다. demo 명령이 전체 예제를 만듭니다.

## 시간과 누락

- timezone이 있으면 Asia/Seoul로 변환하고 없으면 이미 KST로 간주합니다.
- 분·초가 있는 스냅샷을 임의로 정시에 옮기지 않습니다. 별도의 정렬/수집 규칙이 필요합니다.
- 중복 시각/ID, 음수·소수 건수, 비정상 좌표, capacity보다 큰 stock은 오류입니다.
- 빠진 행은 NaN으로 재색인하며 거래 0건으로 채우지 않습니다.
- 수집이 정상이며 거래가 없었다고 확인한 경우에만 0건을 기록하세요.
- stock 없이도 거래 모델을 학습할 수 있지만 품절 정답 평가/추천에는 실측 stock이 필요합니다.
- 이력으로 복원한 재고를 실측 재고와 혼합하지 않습니다.

08시 예측은 08시 시작 재고와 07시 이전 구간 거래를 사용합니다. 08~09시 거래와
09시 재고는 정답이며 입력이 아닙니다. 현재 시각의 거래 정답은 비워도 됩니다.
현재 시각 행과 최소 history시간의 과거 시간축은 필요합니다.

품절 평가는 미래 **정시 재고**가 한 번이라도 0인지 사용합니다. 중간에 잠깐 품절됐다
회복한 사건은 확인하지 못합니다. 그 사건까지 평가하려면 세부 재고 스냅샷이 필요합니다.

저장 모델은 ID 집합/순서를 기록합니다. 새 대여소·좌표 변경에는 재학습이 필요합니다.
부분 지역만 사용할 경우 학습 패널부터 해당 집합으로 구성하세요.

## 원본 검증

실제 ZIP/CSV의 열 이름·인코딩·중복·실제 날짜·수집 장애·운영기간을 확인한 뒤 변환합니다.
파일이 없는 월은 수요 0개월이 아닙니다. 원본 확인 전 정상 자료를 추정해서 만들지 않습니다.
