# 타슈 운영 도우미 시연

[2분 무음 시연 영상](../assets/demo/tashu-map-scenario-2min.mp4)

| 장면 | 내용 |
| --- | --- |
| 0:00–0:13 | 재고와 부족 위험 예측, 묶음 재배치, 차량 경로와 작업표, 계획 질문 |
| 0:13–0:33 | 대전 지도 위 대여소 22곳과 과거 이용 연결 24개 |
| 0:33–1:00 | Flow Matching의 보정값 이동과 대여소별 대여·반납 표본 4개 |
| 1:00–1:16 | 21:00 재고 부족 위험과 작업·복귀 마감 |
| 1:16–2:00 | 6대 수거·배치 경로, 작업 시간표, 복귀까지 걸리는 시간 |

지도는 대전 태평동과 문화동 일대의 실제 도로·하천·철도 자료를 사용했다. 청록색 연결은 고정 GCN이 참고하는 과거 대여소 관계를 표시한다. Flow Matching의 점은 각 대여소의 대여·반납 보정값을 지도 위 해당 지점 주변에 펼쳐 그렸다. 화면은 고정 모델의 표본 128개 중 0~3번을 순서대로 사용하며, 부족 확률은 128개 전체로 계산한다. [OpenStreetMap 데이터와 저작자 표시](https://www.openstreetmap.org/copyright)

2026년 11월 10일 20:50 관측과 직전 관측으로 모델을 다시 실행했다. 보관된 1,294개 대여소의 재고 표본 165,632개와 모두 일치했다. 영상은 과거 연결과 예측 표본, 그리고 도로 위 차량 경로를 순서대로 보여준다. [재생 입력과 검증 기록](../assets/demo/map-scenario-source.json)

수거·배치는 21:00 재고 예측에 맞춰 20:59:30까지 마치는 조건이다. 차량은 작업을 시작한 20:50:15부터 15분 안에 복귀하도록 계산했다. 정차 준비는 1분/곳, 상하차는 20초/대, 최소 작업량은 3대/곳으로 가정했다.

| 계획 시각 | 작업 |
| --- | --- |
| 20:50:15 | 버드내초등학교에서 작업 시작 |
| 20:53:15 | 6대 수거 완료 |
| 20:58:34 | 문화동 센트럴파크(105동)에 6대 배치 완료 |
| 21:00:52 | 버드내초등학교로 복귀 |

왕복 거리는 4.33km이며, 계획 시간은 10분 37초다. 정차 준비 2분, 상하차 4분, 도로 주행 4분 37초를 합산했다. 최종 영상의 길이는 120초이며 음성 트랙은 0개다. [영상 파일 검증](../assets/demo/map-scenario-video-qa.json)
