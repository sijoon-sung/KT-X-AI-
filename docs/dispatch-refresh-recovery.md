# 관측 버전 갱신 시 화면 복구

## 가설

비실험 수정 목적: 원격 관측은 바뀌었으나 로컬 표시 캐시는 최대30초 늦을 수 있다. 기존 화면은409응답 뒤 갱신을 기다리지 않고 같은 캐시를 읽어 재계산이 끝나지 않을 수 있다. 버전 충돌 응답의 최신 표시 자료를 적용하고 제한된 즉시 재시도·실패 후 대기로 복구한다. 예측·라우팅 알고리즘과 기존 연구 계획·결과는 변경하지 않는다.

## 실험

화면의 오래된 버전 요청으로 실제409를 재현했다. 최신 메타데이터의 역순 도착·일시 통신 오류·예측 만료·잘못된 입력을 독립적인 화면 회귀 검사로 확인한다. 검사 실행과 원격 계산은 dislab, 로컬은 표시·전송·브라우저QA만 수행한다. API 재수집·학습·튜닝은 추가하지 않는다.

## 결과

dislab에서 화면 전송 회귀7개·서버 경계8개를 통과했다(코드cffb5c1). 실제 HTTP409응답의`current_info`가 최신 원격 버전을 포함하고,`GET /api/dispatch/info?fresh=1`이 같은 실제 버전을 반환함을 확인했다. 비공개 연결 도우미의 표시자료 조회도 현재 원격 경로를 사용하도록 수정했다.

실패한 요청을 정상 이동0대 결과로 표시하지 않는다. 최신 자료를 받으면 사용자 재클릭 없이 계산을 이어 가며, 만료·연결 오류는 대기 상태로 구분한다. 오래된 캐시가 뒤늦게 도착해 버전을 되돌리지 않고 초기 연결 실패도 화면 초기화부터 재시도한다. 사용자 입력 오류는 자동 반복하지 않는다.

실제 화면 자동 검증은 브라우저 주소를 확인하지 못해 Computer Use 안전 검사에서 중단됐다. 이를 브라우저 검증 통과로 보고하지 않는다. 서버와 회귀 검사 검증 범위를 구분한다. 모델·수량/동선 정책·기존 실험 결과는 바꾸지 않았다.
