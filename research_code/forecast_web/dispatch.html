재배치 계획 만들기

전체 지원 대여소에서 공급·부족 후보를 자동으로 찾습니다. 차량 출발 위치·적재량·목표 재고·주차 한도·상하차 시간을 바꾸면 수량과 방문 순서를 다시 계산합니다. 자동 선정을 끄면 직접 후보를 지정할 수 있습니다.

표시된 날짜의 재고와 고정 예측을 사용하는 계획 화면입니다. 현재 실시간 재고나 실제 배차 결과가 아닙니다.

차량 1대, 거점·주차 허용량·작업시간은 입력 가정입니다. 수거·배치는 예측 적용시각 안에서 계산하며, 묶음 작업 모드에서는 차량 복귀 마감이 별도입니다. 도로 추정이며 실제 교통·차량 진입 가능성은 확인되지 않았습니다.

최대29곳 후보에서 최대8회 방문을 탐색하는 근사 계획입니다. 적재20대는 차량의 한도이며 매번20대를 옮긴다는 뜻은 아닙니다. 실제 수량은 공급지 보호·정차·상하차·복귀 시간을 지켜 정합니다. 도시 전체의 최적 배차나 실제 결품 예방을 보장하지 않습니다.
