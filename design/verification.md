# 발표용 홈페이지 검증 — 2026-11-02

## 가설

비실험 유지보수 목적: 기존 기획의 시나리오와 현재 실측 평가를 구분하고, 문제·기술 선택·수치·재배치·교통 연계·완료 범위를 발표 가능한 순서로 설명한다. 새 성능 개선 가설이 아니며 학습·모형·운영 정책은 바꾸지 않는다.

## 실험

소스 커밋 `295790ad1aad7b2bd3309c8707cf0e192cf5c8b5`를 dislab의 별도 checkout으로 읽어 검사했다.

- JavaScript 구문 검사 통과.
- HTML 발표 장 8개, 중복 ID 없음, 내부 문서·정적 자원·앵커 14개 대응 확인.
- 표준 이벤트 스키마 자체 유효성, 정상 2사례 허용, 잘못된 단위·목적·음수·시각 형식·결측의 0대체 5사례 거부 확인. 시각 대소 비교·실시간 어댑터는 설계이며 구현 검사로 확대하지 않음.
- H13 원 집계의 대여소·표본 수 대응, fairCRPS/MAE/Brier 수치 9개, 현재 유지 대비 fairCRPS 감소율 2개 일치 확인. 새 학습·추론·정확도 평가를 실행하지 않음.

로컬에서는 홈페이지 HTTP200과 실제 브라우저 렌더링, 발표 모드 진입·장 이동·메뉴 이동·마지막 장 경계·Esc 종료·완료 범위 설명 펼치기를 확인했다. 인쇄/PDF 버튼과 인쇄 스타일을 제공하지만 실제 PDF 출력·모바일 기기 검증은 수행하지 않았다.

꺼져 있던 기존 8770 표시 서버와 메타데이터 전송을 복구했다. API 수집·모형 실행·계획 계산은 기존 dislab 경로이며 새 수집 실험이나 기간·쿼터 연장은 하지 않았다. 최신 14:10 관측/14:20 예측에서 UI가 총5대·3.93km·7.8분 계획 계산 완료를 표시한 것을 확인했다. 이는 **동작 확인용 추가 화면 사례**이며 H21 동결 실험·공식 정확도·현장 효과에 합치지 않는다. 계획은 시간 경과와 새 관측에 따라 달라진다.

## 결과

현재 홈페이지에 포아송·FM의 구분, GCN 선택 이유와 XGBoost 직접 우위 미검증, 9월 재고 지표, 0대의 관측 한계, 자원·경로 제약, 후속 교통 연계 설계와 발표 대본을 반영했다. 과거 홈페이지·README는 원래 Git 커밋으로 연결하고 시나리오를 현재 성과로 사용하지 않는다.

PR27은 같은 홈페이지 브랜치에서 갱신하며 미병합이다. 운영 배포·새 모델·교통 서비스 실시간 연결은 미실행이다. 이 브랜치에는 연구 workflow가 없으므로 자동 연구 CI 통과를 주장하지 않는다. 다음 행동은 발표 시 관측·예측 유효시간을 확인하고, 시험 수집이 종료되면 홈페이지에 날짜가 명시된 기록 사례를 사용하는 것이다. 이후 GCN/XGBoost·교통 입력의 추가 가치는 새 가설·사전 Draft PR 후 dislab에서 비교한다.

### 제품 문구 정리

홈페이지에서 발표 문답, 인쇄·대본 버튼, PR·이전 기획 푸터를 제거했다. 결과는 측정한 지표와 감소율을 직접 서술하고, 평가 조건은 별도 항목으로 정리했다. 삭제한 인쇄 버튼의 이벤트 연결도 제거했다. 대본과 연구 기록은 저장소에 남겼다.
