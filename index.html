02 / 예측 모델

GCN·포아송 분포·
Flow Matching의 역할

GCN으로 대여소 특징을 학습하고, 포아송과 Flow Matching으로 대여·반납 건수를 예측한다.

학습 자료 과거 거래 이력 대여·반납 / OD 관계
조건 입력 GCN 대여소 관계 + 시간·기상
확률 예측 포아송 / Flow Matching 대여·반납 건수 시나리오
재고 계산 현재 API와 결합 다음 재고 / 0대 확률

건수 분포

포아송 분포

GCN이 10분 동안의 대여·반납 건수 평균 λ를 추정한다. 이 평균을 이용해 포아송 분포에서 건수 표본을 생성한다.

R, D ~ Poisson(λ)

대여·반납 건수의 조건부 평균과 분산이 같다고 가정한다.

조건부 생성 모델

Conditional Flow Matching

GCN 표현과 예상 거래량을 조건으로 대여·반납 건수의 로그 잔차를 생성하는 속도장을 학습한다. ODE를 풀어 여러 건수 표본을 만들고, 각 표본에서 미래 재고를 계산한다.

noise → count residual → samples

대여소별 대여·반납 2차원 건수를 생성한다. 도시 전체의 공동 이동 궤적은 모델링하지 않았다.

미래 재고 표본 = max(0, 현재 재고 + 생성 반납 − 생성 대여)

포아송과 FM은 별도로 평가했다. 과거 거래 이력으로 학습하고, API는 고정 모델의 입력과 평가에 사용했다. 기상은 관측 이력과 결측 마스크를 사용했다.

03 / 모델 선택

GCN 사용 목적과
XGBoost 비교

과거 이동으로 연결된 대여소의 관계 정보를 예측에 반영하기 위해 GCN을 사용했다.

대여소 관계 정보의 활용

과거 OD로 연결된 대여소의 패턴을 집계해 특징을 학습한다. 이 특징을 대여·반납 건수 예측과 FM의 조건 입력에 사용한다.

버스 정류소나 도시철도역과의 관계를 추가할 수 있도록 구조를 설계했다.

모델 비교 현황

GCN과 XGBoost의 동일 조건 비교는 진행 전이다. 앞선 정적 OD-GCN 비교에서는 우위를 확인하지 못했다.

입력과 학습 방식 비교
관점 XGBoost GCN
관계 정보 OD 이웃 집계 등을 표 특성으로 제공 그래프 이웃 집계와 표현 변환을 학습
거래 건수 count:poisson 사용 가능 포아송 평균을 출력하도록 학습
FM 연결 예측값·특성을 조건으로 사용 가능 학습한 대여소 표현을 조건으로 사용
관리할 점 관계 특성 구성·시차 그래프 품질·추가 학습 비용
프로젝트 결론 동일 입력·예산 비교 전에는 우열 미정
동일 조건 비교 계획

대여소 자체 특성만 사용하는 XGBoost, OD 집계를 추가한 XGBoost, 같은 입력을 사용하는 GCN을 비교할 계획이다. 학습 자료, 시간 분할, 탐색 예산을 맞춰 관계 정보와 학습 방식의 효과를 구분한다. 모델 선택은 과거 거래 자료에서 끝내고, 고정한 모델로 9월 재고를 평가한다.

계산에 반영한 조건

  • 새 관측 수신·만료 임박 시 계획 갱신

수요 관련 입력 · 설계

버스·도시철도

정류소 도착예정정보와 역별 과거 시간대 승하차를 대여소 주변 특성으로 집계할 계획이다. 도보 접근 관계와 노선 관계는 자전거 OD와 구분한다.

버스 도착예정정보에는 승객 수가 포함되지 않는다. 도시철도 사후 집계량은 과거 패턴으로 사용한다.

경로 비용 · 설계

도로 소통정보

도로 링크 속도와 폐쇄 정보를 구간 이동시간과 차량 진입 조건에 반영할 계획이다. 수요 예측과 경로 비용의 효과는 나누어 평가한다.

현재 경로 계산은 OSRM 추정 시간을 사용한다. 실시간 혼잡과 현장 작업시간 연계는 후속 작업이다.

시각 정합 · 설계

예측 시점의 자료 확인

관측·제공·수신 시각과 버전을 저장한다. 예측 시점에 이용할 수 있었던 자료만 입력에 포함하고, 결측과 만료는 마스크로 구분하도록 설계했다.

추가 특성을 사용하는 모델은 과거 자료로 새로 학습·선택할 계획이다.

정류소·역·도로 링크 → 대여소 매핑·시각 정합 → 관계별 표현 / 경로 비용 → 확률 예측 / 재배치

대전교통공사 공식 포털에서 타슈·버스 정류소·도착정보 항목을 확인했다. 이용 승인과 과거 자료 확보가 남아 있다. 도로 링크 데이터는 대전 제공 범위와 이용 조건을 확인할 예정이다.
