02 / 예측 모델

GCN·포아송 분포·
Flow Matching의 역할

GCN은 조건 표현, 포아송과 Flow Matching은 확률 출력에 각각 다른 역할을 맡습니다.

학습 자료 과거 거래 이력 대여·반납 / OD 관계
조건 입력 GCN 대여소 관계 + 시간·기상
확률 예측 포아송 / Flow Matching 대여·반납 건수 시나리오
재고 계산 현재 API와 결합 다음 재고 / 0대 확률

건수 분포

포아송 분포

10분 동안의 완료 대여·반납 횟수를 비음수 정수로 다룹니다. GCN이 조건부 평균 λ를 추정하고 포아송 표본을 생성하는 확률 기준선입니다.

R, D ~ Poisson(λ)

조건부 평균과 분산이 같다는 가정이 있습니다. 재고 자체를 포아송 변수로 둔다는 뜻은 아닙니다.

조건부 생성 모델

Conditional Flow Matching

GCN 표현과 예상 거래량을 조건으로, 잡음에서 대여·반납 건수의 로그 잔차를 만드는 속도장을 학습합니다. ODE로 여러 표본을 생성해 재고의 불확실성을 전달합니다.

noise → count residual → samples

현재 구현은 대여소별 2차원 건수 생성입니다. 도시 전체의 공동 이동 궤적이나 최적 수송 경로가 아닙니다.

미래 재고 표본 = max(0, 현재 재고 + 생성 반납 − 생성 대여)

포아송과 FM은 별도로 평가한 예측 경로입니다. 학습과 모델 선택에는 과거 이력을 사용하고, API는 고정 모델의 입력과 평가에만 사용합니다. 기상은 관측 이력과 결측 마스크를 사용합니다. 전 항목의 실시간 수신은 구현 전입니다.

03 / 모델 선택

GCN 사용 목적과
XGBoost 비교

GCN은 과거 이동으로 연결된 대여소의 관계 정보를 예측에 반영하기 위해 사용했습니다.

대여소 관계 정보의 활용

과거 OD로 연결된 대여소의 패턴을 집계해 특징을 학습합니다. 이 특징을 대여·반납 건수 예측과 FM의 조건 입력에 사용합니다.

버스 정류소나 도시철도역과의 관계도 추가할 수 있습니다. 다만 관계를 추가했을 때 예측에 도움이 되는지는 별도 비교가 필요합니다.

현재 증거의 범위

동일 조건의 GCN 대 XGBoost 직접 비교는 미실행입니다. GCN의 추가 정확도·속도·새 대여소 일반화 이득은 아직 입증하지 않았습니다. H7의 제한된 OD-GCN 비교도 우위를 지지하지 못했습니다.

모형의 설계 차이 · 성능 순위 아님
관점 XGBoost GCN
관계 정보 OD 이웃 집계 등을 표 특성으로 제공 그래프 이웃 집계와 표현 변환을 학습
거래 건수 count:poisson 사용 가능 포아송 평균을 출력하도록 학습
FM 연결 예측값·특성을 조건으로 사용 가능 학습한 대여소 표현을 조건으로 사용
관리할 점 관계 특성 구성·시차 그래프 품질·추가 학습 비용
프로젝트 결론 동일 입력·예산 비교 전에는 우열 미정
동일 조건 비교 계획

같은 과거 시간 분할·대여소·기상·달력과 정해진 탐색 예산으로 자기 특성 XGBoost → OD 집계 추가 XGBoost → 같은 입력의 GCN을 비교합니다. 관계 정보와 학습 표현의 이득을 분리하고, 선택은 과거 거래 내부에서 끝냅니다. 고정 모델만 9월 재고에서 평가합니다. 새 가설 PR·사전 계획 후 dislab에서 수행할 후속 비교이며 아직 결과가 없습니다.

원문: GCN · XGBoost · XGBoost 목적함수

MAE는 예측분포 중앙값의 수량 오차, Brier는 예측한 0대 확률의 오차입니다.

FM의 추가 이득은 아직 확인되지 않았습니다.

FM의 fairCRPS는 같은 GCN·포아송 대비 0.327% 높았습니다. 두 기준선 모두를 이겨야 한다는 사전 기준을 통과하지 못했습니다. FM 연구 경로를 보존한 시제품이며, ‘FM이 포아송보다 우수하다’는 결론은 아닙니다.

9월은 반복 노출된 평가 자료로 미열람 독립 시험이 아닙니다. 대응 표본 수가 독립 표본 수를 뜻하지 않습니다. 과거 거래·대여량 점수와 구분합니다. H13 학습의 로컬 실행 위치 위반·dislab 전체 평가 전환은 원 기록에 공개했습니다.

시각 정합 · 설계
